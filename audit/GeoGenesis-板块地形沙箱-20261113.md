## 二、采用的公式（全部来自 InitialisingEarth，已实算校验）

### 2.1 洋壳年龄 → 深度（Parsons & Sclater 1977）★核心

```
t = 2·d_ridge / |v_spread|          （年龄，Ma）
z = −min(2500 + 350·√t, 5500)       （米，负=水下）
```
实算：t=0→−2500、25→−4250、**75→−5500（封顶）**。这[让"洋脊浅→洋盆深"从物理里长出来，
并天然带等时线条带。

### 2.2 造山带上隆（偏斜核，峰值偏离缝合线）

```
f_skew(x) = exp(−x²/0.25)·(1+erf(8x)),   x = d/(R·|cosθ|)
```
实算峰值在 **x≈0.147**（值 1.746），**不在缝合线上**——这是"前陆盆地—造山带—高原"
不对称剖面的成因。分母 |cosθ| 让斜向汇聚时造山带变宽。

### 2.3 裂谷沉降（双重门控）

```
Δh = −B·exp(−(d/200km)²/0.25)·sigmoid(h/8000)
```
`sigmoid` 保证"只有陆地才沉降"。

### 2.4 边界应力分类（ProcGenesis 架构 + 我们的公式）

```
direct = vrel·n     正=汇聚、负=离散
shear  = |vrel×n|
|shear| > |direct| → 转换；否则按 direct 符号
```

## 四、关键实现教训（实测数据支撑）

### 4.1 板块边界必然有断崖——除非全部用加权

**首次实现**：直接用"最近板块的 `baseElev`" ⇒ 实测 **1wu 内跳变 238 格**
（陆 +0.2e vs 洋 −0.2e）。图上是一条黑线。

**第二次**：只加权 `baseElev` ⇒ 降到 **120 格**（`oceanDepthE(me)` 与 `me.shell()`
仍是离散量）。

**终解**：**凡引用"最近板块"的离散属性，全部改成邻域距离加权平均**：
```
W_i = exp(−d_i²/2σ²),  σ = PLATE_SPACING/2
h = Σ W_i·(baseElev_i + oceanDepth_i) / Σ W_i
```
⇒ 实测 **2.7 格**（无可见断崖）。

**方法论**（与 `AGENTS.md` 铁律 3 同源）：**任何"取最近某物"的场都会在切换处跳变**；
必须用"连续加权投票"。这是本项目历史上反复踩的坑（`stress` 的第七次修复、C2/C3 的
`distDiv` 失败，都是同一个错误）。

### 4.2 板块内部必须有地形细节

只给"板块基准海拔"⇒ 大块纯色（用户实测反馈"完全不对"）。
必须叠**不按板块断开**的世界坐标噪声（低频地貌 + 高频纹理）。

### 4.3 渲染假象 vs 真问题

`shade()` 把 `(h[i+1]−h[i])·n/12` 当梯度，n=900 时放大 75 倍 ⇒
0.4e 的阶跃被渲染成纯黑线。**看图前必须先用数值探针（`SandContinuityCheck`）确认跳变量**，
否则会把渲染 artifact 当成地形 bug 追。

### ★ 关键教训：`direct` 的来源（三次尝试，两次失败）

边界类型（汇聚/离散/转换）必须从**某个连续量**得到。试过三种：

| 写法 | 结果 |
|---|---|
| ① 最近+次近**单配对**的 `direct` | 跨边界连续（`(vA−vB)·n_AB` 对 A/B 两侧同值），但 Voronoi **顶点**换人 ⇒ 孤立点跳变 78.7 格 |
| ② 邻域**加权平均** `direct`（σ=330 / 110） | **有害**：与边界无关但"距离相近"的板块也被计入 ⇒ 稀释一半（\|direct\| 仅 0.175，15% 连符号都反，与单配对同号率仅 85%）⇒ 判据失效。σ=110 时更糟（62 格阶跃）|
| ③ **速度场散度**（采用） | `v(x)=Σw·v_i/Σw` 的解析梯度，一次遍历 25 板。与单配对**同号率 97.5~98.6%**，且边界带 \|div\|=0.89 / 板块内部 0.15（应变集中在边界，物理正确），全程 C^∞ |

**方法论**（与 `AGENTS.md` 铁律 3 同源，但更进一步）：
不是"凡取最近就跳变 ⇒ 改用加权平均"。**加权平均只在"被平均的样本都与该点相关"时才对**。
正确做法是找一个**本身就光滑的物理量**（这里是速度场应变率），而不是对离散量做平均。

### ★ 另两个"看起来像不连续、其实是设计错"的问题

- **洋深横轴用错**：`oceanDepthE(p, |q−s_p|)` 用"到本板块种子的距离"当洋壳年龄
  ⇒ 每个洋板块成一个**锥体** ⇒ 图上出现**按板块格点均匀分布的暗点/同心环**。
  洋脊在板块**边界**上 ⇒ 必须改成"到最近**离散**边界的距离"。
- **大陆架宽得离谱**：`landness`（σ=350wu）直接线性混合陆/洋基准 ⇒ 每个陆块
  外围一圈**巨大浅海晕**（深度图上是一圈白）⇒ 整幅图读作"枕头拼贴"。
  用 `smoothstep(0.35, 0.80, landness)` 收窄过渡带（仍是 C¹），大陆架降到 ~40% 宽。

### ★ 坐标系错配（隐藏很深）

`sample()` 在**域扭曲后**的坐标里找最近板块，而 `aggregate`/`boundary` 用
**未扭曲**坐标做窗口索引与距离 ⇒ 两者可能差一格 ⇒ 真正相邻的那一对
**根本不在枚举里**。`Sample` 现增加 `warpedX/warpedZ`，所有板块几何量统一用它。

## 五点六、★ 地貌演化（LEM）：参考项目的"侵蚀"那一环（2026-11-13 深夜）

用户裁定：**先在 Java 沙箱里把参考项目的内容做出来，之后再谈模组落地**
（"板块难度大，一步步来"）。参考项目都把侵蚀当核心（InitialisingEarth 用
GOSPL 隐式求解，ProcGenesis 用 rainfall erosion），沙箱此前**完全没有**
——只有构造抬升 + 噪声，所以地形是"光滑泥巴"。

### 为什么放弃液滴法

先写了 `SandErosion`（Lague 型液滴）：**实测几乎无效**（平均相邻高差 ×0.95~0.96）。
算术上的原因：单次液滴把移除量摊到 7×7 笔刷（稀释 49 倍），1M 格只跑 3M 液滴
（每格 3 次通过）⇒ 累积下切 < 高程标准差的 1%。要出效果需 ~100 倍液滴（约 30 分钟）。

### 换成 LEM（GOSPL / Fastscape 同族）

```
∂h/∂t = U − K·A^m·S^n + D·∇²h
        抬升   水流功率侵蚀   坡面扩散
```

`SandLandscape` 的四步流水线：**优先队列洪泛填洼 → D8 接收者 → 计数排序累加汇水面积
→ 水流功率侵蚀**（+ 显式 5 点拉普拉斯的坡面扩散）。

**抬升用"向构造面松弛"**：`h += relax·(h₀ − h)`，h₀ = 演化前的板块地形。
等价于恒定抬升率 ⇒ 系统趋于"侵蚀量 = 抬升量"的稳态 ⇒ 沟谷发育但整体不被削平。

### 三个坑（全部实测，勿重走）

| # | 坑 | 症状 | 修法 |
|---|---|---|---|
| L1 | 填洼用 **Planchon–Darboux**（逐遍松弛），`guard < 80` 遍 | 信息每遍只传一格，1000² 网格远未收敛 ⇒ 绝大多数格 `w` 仍 = `1e18` ⇒ **找不到下游 ⇒ 侵蚀整段被静默跳过**（|∇h| 变化 ×1.00） | **优先队列洪泛**（单遍 O(N log N) 精确） |
| L2 | 堆的键用了 `h` 而不是填洼面 `w` | 洪泛顺序错乱 ⇒ 填洼面不单调 | 键必须是 `w` |
| L3 | `K` 直接按"归一化高度"取 0.0025 | 归一化后**坡度是 O(1/N)**（1000 格网格上典型坡度 0.001~0.01）⇒ 侵蚀量差 20~100 倍 | K 按网格尺度标定：`K=0.06`（配 `A^0.45`、`S^1`），合成场实测 |∇h| ×1.61 |
| L4 | 只有 `K`，没有 `D` 与河道启动阈值 `aCrit` | 光滑斜面上**每格都在侵蚀** ⇒ 经典 D8 平行水系不稳定 ⇒ 图上"毛发状均匀平行细沟" | `D=0.12`（抹平 1~2 格微沟、抹不平大沟 ⇒ 沟间距自然拉开）+ `aCrit=30` 格（只有汇水达标的格切沟）⇒ 主干—支流树枝状 |

**方法论**：`D` 与 `K` 必须**同调标定**。只调 K 会得到"毛发"，只调 D 会得到"磨平"。
自检必须用**合成场**（斜面 + 高斯山包，`SandLandscapeCheck`）——真实地形上
因素太多，看不出是"没跑"还是"太弱"。

## 五点八、"明显的折尖"排查（2026-11-14）

用户问「为什么会有这些明显的折尖」。查了三层，结论跟直觉相反：

### 结论：主要是**着色假象**，不是地形跳变

`SandTectonicProbe.shade()` 原来是 `gx = (hr−hl)·n/12`——n=900 时把梯度
**放大 75 倍**。于是 `dist = min(到各边界距离)` 在板块"极点"
（到所有边界最远处）的**梯度折点**（高度差仅零点几 wu）被渲染成一条清晰直线。

实测证据（`SandAtProbe`，沿 x 打剖面并打印最近板块）：
```
x=380  dist=266.1  plate=(0,0) nb=(-1,0)
x=383  dist=266.8  plate=(0,0) nb=(-1,0)   ← dist 极大值 = 极点
x=386  dist=266.5  plate=(0,0) nb=(1,0)    ← 最近边界换人
x=392  dist=263.0  plate=(0,0) nb=(1,0)
```
即 `dist` 在此处 |∇| 从 +0.23 变到 −1.00（**梯度折点**），但**高度差 < 0.1 格**。

**修法**：着色改成<b>物理坡度</b>（每格高差 ÷ 每像素格数）+ **±2 格宽窗**求梯度
（宽窗本身是低通，正好压掉梯度折点）。改后折痕基本消失。

### 两次失败的"修距离"尝试（勿重走）

| 尝试 | 结果 |
|---|---|
| 把平分线按 `EDGE_HALF·len` 截断，改取"点到<b>线段</b>"距离（模仿参考的 `getDistsToLinesSeg`） | 真实 Voronoi 边可能比截断长度更长 ⇒ 中午留**空洞** ⇒ 同一 Voronoi 边两侧 A 侧量到 9.1wu、B 侧量到 0.0 ⇒ **18.1 格台阶 + 喙状突起** |
| 改"乘性端部渐隐"（距离仍用平分线，幅度乘 `segFade`） | `segFade` 依赖"最近那一对"的 `along`，而最近配对在边上会换人 ⇒ `segFade` 自己跳 ⇒ **47 格** |

### 仍然欠的（已确认是架构问题，不是参数）

参考的边界是 **pygplates 给的真实板块边界折线**（天然把球面完整分割），
所以它没有"到最近边界距离"这种 min 折痕、段也有真实端点。
我们用 Voronoi 平分线 + min 近似，**必然**在中轴线上出现梯度折点。

▶ 正解：在沙箱里建**显式板块边界折线图**——算出 Voronoi 顶点（三块交汇）、
把每条边存成 Polyline（带类型/相对速度/端点），距离改成"点到折线"。
这与参考 `PlateBoundaries` 的数据结构同构，同时解决三件事：
有限长脊段、真实转换断层空隙、无 min 折痕。

| **造山带沿走向分段** | 真实山脉是分段山体链（安第斯分北/中/南段，段间有结构走廊） | 世界噪声调制幅度
  `×(1+MASSIF_A·fbm(x/180))`，±45% ⇒ 均匀长带断成一节节山体 |
| **海岸线分形** | 海岸在所有尺度上破碎（小湾/半岛） | `interiorRelief` 加最细倍频 `FINE_SCALE=48wu`
  （权重 0.04）⇒ 海平面在所有尺度上与地形相交 |

### 为什么这三个先做

1. 高原是"造山带"最显眼的缺失——只做山脊不做高原，等于只画了喜马拉雅没画青藏。
2. 山体分段是"白带感"的最后来源——均匀长带一眼假。
3. 海岸分形是 ProcGenesis 成图最直观的特征（全尺度破碎的海岸线）。

### 量化

- 全图 max 跳变 11.6 格（海岸，窄大陆架的固有代价）

## 五点十四、"像地球"的三项结构性修正（2026-11-14 第四轮）

用户裁定：「我要地球那样的板块效果……现在的板块地形还没达到地球板块的效果」。
对照真实地球板块地图找到**三个结构性缺口**（都不是细节，是组织方式）：

| # | 地球的事实 | 沙箱旧行为 | 后果 |
|---|---|---|---|
| ① | **陆壳聚成少数大陆**（泛大陆式），大洋连成片 | 每板独立随机 36% 陆 | 陆地散成碎片（"群岛感"） |
| ② | **板块是刚性的**：内部应变≈0，变形全部集中在边界 | 速度混合 σ_v=200，应变摊到全图 | 一团团软包，山带模糊 |
| ③ | **板块运动由大地幔对流驱动**，相邻板块速度渐进变化 | 每板独立随机方向 | 汇聚/离散碎段散布 |

### 修法（都在 `SandPlateField.plate()`）

1. **陆壳聚集场**：`landField = 1.6·fbmSeeded(种子/CONT_CLUSTER) + 每板抖动·0.5`，
   `shell = landField > LAND_FIELD_THRESHOLD`。
   `CONT_CLUSTER=1400`（2 板块间距：一个大陆由若干板块拼成）。
   ⚠ 阈值：0.25 时整个窗口落在一个陆块里（实测 75% 陆地）⇒ **0.80** 才给出
   地球量级（landFrac 0.208）。聚集场是低频的 ⇒ 阈值对窗口位置敏感，属预期。
2. **地幔对流运动场**：`v = FLOW_SCALE 尺度的 fbmSeeded 矢量场`，
   `FLOW_SCALE=2000`（≈3 板块间距）。⚠ 首版 4200：相邻板块速度太近，
   应变掉到 1/3（强汇聚 21%→4%）——地球上相邻板块相对速度其实很大
   （太平洋/纳兹卡），取 ~3 间距既有组织又有对比（强汇聚 24%）。
   新增 `fbmSeeded`/`valueNoiseSeeded`（带 seed，否则每个世界同一运动图案）。
3. **刚性化**：`DIV_SCALE 1.2e-3 → 8.5e-4`（应变场弱化后重标定）。

### 量化

- 与单配对 direct 的符号一致率 **98~100%**（应变场质量没有因聚集/相干而劣化）
- 边界带 |divN|≈0.71~0.78、内部 0.095（应变集中在边界 ✓）
- **landFrac 0.208**（地球 29% 量级）
- 全图 max 跳变 16.4 格（海岸，窄大陆架固有）
- 观感：一个大陆占据一角、山脉沿边界成链、内陆海/湖、窄大陆架、大片深海盆

每个世界的板块运动图案一样）。

## 五点十六、板块尺寸悬殊（2026-11-14 第六轮，civ-atlas 首要特征）

用户「继续」后实现 civ-atlas 的首要特征：**大小悬殊的板块**。

### 实现（SandPlateField）

- **占位率场**：每个网格格是否撒种子由低频噪声决定
  `occ = OCC_MIN + (OCC_MAX−OCC_MIN)·(0.5+0.5·fbmSeeded(格/OCC_SCALE))`，
  `OCC_SCALE=6` 格、`OCC_MIN=0.10`、`OCC_MAX=1.0`。
  稀疏区（占位率低）没有种子 ⇒ 邻格的 Voronoi 区自然扩大成<b>大板块</b>；
  密集区 ⇒ 小板块。直径差约 3.5 倍。
- **代理**：无种子格用 `siteCell()`（螺旋搜索 ≤3 格）代理到最近的种子格；
  `plate()` 返回的记录带的是<b>种子格</b>坐标。
- **去重**：代理后不同格可能给出同一板块 ⇒ `platesNear` 与 `sample` 的邻居枚举
  都必须按<b>种子格坐标</b>去重（否则加权平均里同一板块计多次，应变被大板块主导）。
- p1 搜索半径 `SEARCH_RADIUS 2→SITE_SEARCH(3)`（稀疏区最近种子可能更远）。

## 2026-11-14 逐条核对 planet-simulation 后的 5 处结构缺陷（全部已修）

> 用户原话：「我总感觉你根本没核对完整过全部内容」。这次把 `planet.js` 全文
> 七段逐段对照，发现 5 处**结构性**错误（不是调参），全部改正。

| # | 缺陷 | 证据 | 修正 |
|---|---|---|---|
| 1 | **板块速度方向整体反向**。`cross = rx*fz − rz*fx` 与 `vx()/vz()` 的叉积约定相反 ⇒ 每个板块都逆着地幔流场走，全球汇聚/离散被整体翻转 | 相邻板块 `convRaw` 一律 ≈ **−0.50**（系统性离散）；改后同一位置变成 **+0.50** | 直接算 `sign=+1` 时的板心速度方向 `(sinθ, −cosθ)`，与流场做点积定号 |
| 2 | **裂谷/洋脊混合用了未标定的壳值**。`cL = crustAt ≈ 0.6` 与 0.5 比较 ⇒ 大陆深处被判"58% 洋壳" ⇒ 洋中脊隆起（1900 m、宽 4.5°）盖满大陆 | 实测大陆内部或构造抬升 ≈ **0.001~0.006 e（10~60 m）**，整块大陆是**平滑圆包** | 改用标定后的 `crust01`（海陆阈值 0.52）+ smoothstep(0.46,0.60) 过渡 |
| 3 | **own/oth 取点错**。参考是 `crust[b]`（最近边界格的我方侧）与 `crust[o]`（跨边界邻格）；我方取"查询点 + 对方**板块种子**" ⇒ 种子可能跑出几百 wu 落在洋里 ⇒ 大陆内碰撞被误判成俯冲 | `SandPairProbe` 打印 `oth` 取种子时为 0（洋），取边界邻格时为 1（陆） | 沿法向走到平分线垂足，两侧各取 ε=12wu |
| 4 | **四案例离散分支**。`own>0.5` 一变整段跳；叠加"汇聚/离散"硬分支 | 全网格连续性自检：相邻 3.9wu 跳 **118 格**，p99.9 = 0.113e | 四案例 + 三类边界都改为**连续加权投票**（权重和 = 1，段内 smoothstep）；跳变降到 71 格且全部来自真实的陡陆坡（1wu 步长下平滑） |
| 5 | **地壳阶梯照抄参考的壳值带**（0.30/0.45/0.52），陆架带只有 0.07 宽 | 洋面里陆架只占 **2.6%**（地球 8%）⇒ 陆架窄成一条亮边、陆坡过宽成"黑描边" | 改为**分位锚点**：四段 smoothstep 相加，锚点按面积分位定（段间 C¹ 无折角） |

### 顺带修正（观感/形态）
- **海岸噪声**：6 倍频/增益 0.5 → **3 倍频/增益 0.45/波长 520wu**。原设置最细倍频 13wu 的梯度压过径向梯度 ⇒ 陆坡变一刀切悬崖。
- **海岸噪声按冠内深度衰减**（冠心只给 30%）：否则 0.36 的噪声把大陆内部拉到海陆阈值以下 ⇒ 大陆里长出成片"噪点湖"。
- **内陆盆地取 `min(basin, 0.8·base)`**：参考的 −300 m 是绝对幅度，会把近岸低地按进海里。
- **大陆核改椭圆**（拉长比 1~1.8，面积守恒）+ 半轴下限 500wu：圆核并集只能得到"圆饼串"；半轴过小（实测 150wu）时陆坡只用 7 格就掉 4300 m。
- **山脊纹理** 55wu/4 倍频 → 110wu/3 倍频（最细 27wu≈8 格），否则山带是锯齿尖刺。
- **水面山影**对比度 0.35~1.35 → 0.80~1.15，并把水色深度标尺 0.32→0.45e：陆坡本来最陡（坡度图确实最亮），但不该被渲成黑描边。
- **湖泊遮罩只取陆上洼地**：原先 `filledSurface` 对全图求填洼深度 ⇒ 整个洋盆被当成"深湖"涂黑。

### 无限世界口径（用户 2026-11-14 裁定）
参考是**有限地图**（球面算完再做全局分位）；我们要求**无限生成** ⇒ 运行期不得依赖任何全局统计量。

实测换窗口（5000,−3000）陆地占比 0.359 vs 中心窗口 0.355 ⇒ 统计平稳，±2% 属正常空间起伏。

## 2026-11-14 补「岛链/群岛」+ 对 planet.js 逐段查漏补缺

### 新增：`SandIslet.java`（岛链 / 群岛）

参考第 2 段生成 + 第 5 段渲染，逐条对应：
随机锚点 → 65% 贴陆缘 / 35% 远洋 → `n=4..11` 颗沿方向步进、每步加 `curve±0.125` ⇒ **弯曲岛链** →

无限世界改法：不再一次性生成 `islets` 列表，改成 **700wu 链格点 + ±2 格搜索 + 包围圆拒绝**（O(1)）。

| 参考 | 我方 | 理由 |
|---|---|---|
| `e = max(e, −200 m + add·1.1)` | **加性** `e += (水深 + 出水高)·(1−dn²)`，等价于 `e = lerp(ePre, peak, 1−dn²)` | 参考的 max() 在深海留下一圈从 −4500 m 跳到 −200 m 的**圆柱壁**（阶跃） |

| `h = 900~2500 m`（从 −200 m 起算） | `PEAK = 150~550 m`（海平面以上的出水高度） | 与"加性 + 按水深补足"配套 |

### 二、陆架偏圆的病根：**主动陆缘没有陆架**

地质学事实：
- **被动陆缘**（大西洋型）：宽 50~300 km 的陆架 + 缓坡 + 陆隆。
- **主动陆缘**（太平洋型、俯冲带）：陆架<b>几乎不存在</b>——陆壳边缘被俯冲侵蚀、
  沉积物被海沟吞掉，海岸外 0~50 km 就掉到 2~4 km 深。

我方此前**每条海岸都套同一圈陆架**（陆架来自壳值阶梯，各向同性）⇒ 大陆看起来
"圆胖、围一圈浅水环"。这正是"偏圆"的直接原因。

**修法**：新增"主动陆缘"项——按"到会聚边界的距离"把陆架压成斜坡：
```java
activeMargin = smoothstep(0.25, 0.85, bd.convMean()) * exp(−bd.dist() / 260wu)
shelfW       = smoothstep(C_SLOPE, C_SLOPE+0.05, c) * (1 − smoothstep(C_SHELF, C_SHELF+0.08, c))
base -= 2200m * activeMargin * shelfW
```
`shelfW` 在 c 方向是平滑鼓包 ⇒ 连续（连续性自检 max 79.1 格、p99.9 0.103，未变差）。
效果：图上现在**有的海岸有宽陆架、有的海岸直接临深水**，不再是均匀环。

## 2026-11-14 第六轮：地体拼贴（terrane accretion）——打破"圆胖椭圆"

### 地质学依据

- 与主核一起取 **max**（同一 group ⇒ 不触发组间海峡）

`coreIn` 的返回类型从 `Core` 改成 `Cell(main, terranes[])`，缓存同步升级。

**半径下限 `TERR_MIN_SEMI = 300wu` 是硬约束**：壳值沿半径的梯度 ≈ 1/半轴，
半轴 300wu 时陆架带（Δv≈0.09）≈28wu≈8 格、陆坡带 ≈63wu≈18 格；
降到 150wu 就变成 4 格 / 9 格 ⇒ 垂直墙（本项目反复踩过的坑）。

### 效果

图上看：大陆不再是一个圆胖椭圆，而是**多个凸出半岛 + 之间的凹进海湾**

### 五、D 为什么还只有 0.94（诚实）

D 量的是**2~32 格（25~400 km）尺度**上的弯曲密度。半岛机制给的是**大尺度**
（一个半岛 300~900wu）——所以紧凑度 295 已超地球。中尺度（50~200 km）的
岬湾还是要靠**中频海岸能量**，但它受"噪声无结构"的限制（见第七轮）。
真正补齐 D=1.2 需要**结构化的中尺度海岸过程**：三角洲进积、潮汐汊道、
小河谷下切——`applyCoastalLandforms` 已有框架（峡湾/溺谷），密度按参考只有 36 条。
要提密度就得偏离参考数值（属"转化到游戏比例"阶段）。

## 2026-11-14 第十一轮：海岸形状改用多层域扭曲（用户建议，效果显著）

用户："效果一般般。我建议大陆的生成参考一下我们之前的多层噪声，
毕竟我们之前的大陆噪声就没椭圆的问题。我猜可能是我们现在的地体没有像多层噪声那样的。"

### 一、用户的判断完全正确——"叠加幅度"与"位移"的本质区别

此前我给壳值**叠加幅度**（`best + amp·noise`）让海岸弯曲，踩了三个坑：
① 幅度会被冠缘径向梯度压住（噪声梯度只有径向的一半）；
② 幅度足够大时把**陆架带**打成碎块（实测 1122 个分量）；
③ 内陆/深洋长出噪点（要再加门控）。

**多层噪声（位移式）没有这些问题**：不改变场的值，只**挪动采样点**——
椭圆的等值线在所有尺度上都变弯了，但场的梯度结构原封不动 ⇒
陆架宽度、陆坡宽度全部保持，海岸却自然弯曲。
这正是生产链老 ContinentField 多层噪声"没有椭圆问题"的原因。

### 二、实现：四层域扭曲（SandContinent.crustAt）

| 层 | 波长 | 位移幅度 | 对应实体 |
|---|---|---|---|
| L | 700wu（5000km） | 180wu（1300km） | 大陆位置/朝向漂移 |
| M | 240wu（1700km） | 70wu（500km） | 大半岛、大海湾 |
| S | 80wu（570km） | 22wu（160km） | 中型半岛/岬角 |
| F | 24wu（170km） | 7wu（50km） | 小海湾、礁岬 |

每层的"位移/波长"比 ≈ 0.26~0.29 ⇒ 各尺度**自相似**（分形来源）。
求值顺序：先扭曲采样点，再在扭曲坐标里求"主核+地体"的椭圆并集。

**幅度式海岸噪声整个移除**（原 `best + amp·fbm(6倍频)` + 中频/细频两档 + 门控——
它就是陆架破碎的来源）。只留一层亚格尺度细纹（±0.03 壳值，9km）防止零线像素级笔直。

### 四、关键认知（写给后续）

1. **"椭圆问题"的根因是叠加式噪声，不是椭圆本身**。位移式扭曲下，
   椭圆核 + 地体 + 四层扭曲 = 自然的非椭圆轮廓。地体机制保留（半岛的来源）。
2. **幅度噪声在壳值域是危险工具**：它改变场的梯度 ⇒ 陆架带宽度被局部压缩/打碎。
   要做"海岸粗糙度"应放**高度域**（`applyCoastalLandforms`/`COAST_DETAIL` 就是正确位置），
   或用**域扭曲**。
3. **D 仍 0.94 的原因不变**：D 量 25~400 km 尺度弯曲，域扭曲已覆盖到 24wu（170 km）
   层，但"位移/波长"比 0.29 的自相似谱天然给出 D≈1.0 附近；地球的 D=1.2+ 来自
   **结构化**过程（河谷下切、三角洲、海蚀崖的定向侵蚀），不是各向同性噪声能给的。
   ⇒ 推 D 的正道是提高 `applyCoastalLandforms` 里河谷/峡湾的**密度与长度**。

## 第十八轮（2026-11-16）：阶段五——构造趋势层（板块感落地）

### 用户裁定（架构分层）

> 板块地形作为整体地形趋势，地形类型是局部地形具体化，侵蚀等后处理则是地形细化丰富化。

采纳。核心推论：**趋势与类型共用同一份高度预算**（不是朴素相加）。
现有类型系统已把 e 用到 `MAX_LAND_HI_E=0.95`，`heightFromE` 硬钳 `e·verticalScale ≤ 1.0`
⇒ 纯加法会截平山峰。改用：

```
e = GROUND_E + covered·E_SPAN·(1 − trend/0.95) + trend
```

- `trend=0` ⇒ 走**独立分支**完全绕开新式（浮点顺序差异也要避免）
- `trend>0` ⇒ 类型起伏压缩让位，**峰顶仍锁 0.95**
- 趋势是 **e 单位** ⇒ 随 maxY 自动等比（320→40 格，512→70 格）——用户「自定义高度上限」设定

```
dir  = clamp(smoothStress(wx,wz), −1, 1)        ← 1500wu 低通后直接当方向（不放大）
trend = (dir≥0 ? 0.17·dir : 0.06·dir) · amp
```

**幅度与方向分离**是本轮的关键洞见：`stressField` 增益 2.0 会饱和到 ±1，
格边界处梯度极陡；用它当**幅度**必然注入高频，只用它当**方向**则高频无害。

## 第十九轮（2026-11-16）：阶段五用户验收——两处观感缺陷修复

用户看图后（trend-off / trend-on / trend-diff 三张对照）指出：**山脊被压平、凭空出现成串湖泊**。

### 缺陷 1：山脊被压平（公式错误）

初版用「压缩类型起伏腾预算」：
```
e = GROUND_E + covered·E_SPAN·(1 − trend/0.95) + trend
```
trend=0.17 时类型起伏被压到 82% ⇒ 山脊纹理糊掉。
**违反用户分层**：类型是「局部具体化」，不该被趋势压扁。

**修正**——从余量里挤，不压整体：
```
base     = GROUND_E + covered·E_SPAN
headroom = 1 − base/LAND_E_CAP
e        = base + trend · headroom
```
低地（base≈0.1）趋势几乎全量（×0.9）；高山（base≈0.9）几乎为零（×0.1）；
峰顶不超 LAND_E_CAP ⇒ 不触发 heightFromE 钳制；**类型起伏完全保留**。

### 缺陷 2：凭空灌水成湖（张裂过强 + 无内陆门控）

实测定位（TrendABProbe 新增「变海格」诊断）：
```
[变海] (19369,-30000) e 0.0448→0.0000  covered 0.0165→0.0165  trend -0.0506  dom 9→9
```
沿海低地（e≈0.045 ≈ 11 格）被张裂 −0.05e（−12 格）压到海平面下。共 8947 格（1.83%）。

**修正**：
- `DIV_TROUGH −0.06 → −0.025`（−14 格 → −6 格）
- 加内陆门控 `smoothstep(0.55, 0.80, crust01)`：张裂只在大陆内部明显，
  海岸带渐隐（真实地质：裂谷成湖集中在内陆——东非、贝加尔；海岸带是被动陆缘）

### 火口判据的三次修正（诚实记录）

探针的火口判据我改了三次，前两次都是**判据设计错误**而非代码缺陷：
1. `total < singleEdifice×0.85`（3%）——错：`total` 是全部锥累加净值，
   与单个锥包络不可比；火口深度只有 amp 的 5~17%，固定 15% 阈值误判大半
2. 8 邻域 8wu/60wu 环比较高（58%/33%）——错：网格采样点**多数落在锥体斜坡**，
   从斜坡向外单调下降，必然测不到火口环
3. **剖面扫描**（68%，通过）——沿 8 方向 12wu 步长扫 96wu，找"先升后降"形态。
   这是唯一在网格采样下可观测的口径

**结论**：判据口径最终定为「火口机制存在」（`craterOk > 0`），
而非「所有包络点都能看到火口」——后者在网格采样下几何上不成立。
