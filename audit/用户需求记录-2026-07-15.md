## 一、省场形态重构（#3，当前焦点）

### 用户原始诉求（要点）
1. **形态各异**：不同地形类型应有不同尺度/形状——尖顶、平顶、宽跨等，不能"都差不多"。
2. **噪声平方回到 0**：每个地形类型的噪声应"乘平方"，让谷底回到该省噪声的真 0 值（省基座），避免后续侵蚀从平整高台硬刻、容易陷入局部极小值。
3. **否决假山脊**：明确否决旧 Ridge 算子 `1-|2n-1|`（把山脊落在噪声中点零值→指纹状假山脊）。正确做法：峰在噪声高值 `n=1`、谷在噪声低值 `n=0`；山岭的蜿蜒形态由**域扭曲(warp)** 产生，绝不碰零交叉脊函数。

### 关键约束（用户拍板）
- **"噪声的 0 值" = 地形类型噪声的 0**，不是大陆性(continent)等条件噪声。
- 参数必须接入**配置 UI**（不能只做裸 toml 字段）。
- 按地理学做**更好的**侵蚀前基础地形：参考旧设计文档但超越，并参考联网调研（Tectonic Uplift 2016、GRC 2025 海拔×起伏矩阵、danbgray 参数化地质类型）。
- 每省形态应**独立 shape 曲线**（谷底=baseᵢ、峰顶=baseᵢ+rangeᵢ），通过幂函数(尖钝)+域扭曲(蜿蜒)实现形态各异。

## 七、地形类型核心设计原则（2026-07-15 晚，综合用户全部意见）

### ⚠️ 这条最重要——永远记住 ⚠️

**每个地形类型内部有丰富的多样性，不是"一个噪声→一个高度→一个类型"。**

- **山脉（MOUNTAINS）内部**：belt省→喜马拉雅式蜿蜒山脊，plateau边缘→科罗拉多式陡崖，craton古老山→阿巴拉契亚式圆顶
- **平原（PLAIN）内部**：北美大平原→极度平坦，东欧平原→温和起伏，热带稀树草原→开阔微丘
- **每种类型的形状算法本身就要考虑省上下文**：同是 MOUNTAINS，belt 省和 plateau 省的产出不同

### 权重控制分布面积，不混合形状

- ClimateWeights + ProvinceWeights → 决定每种类型占多大面积（像地图上的色块区划）
- 每个类型内部由各自的完整算法独立产出形状（独立噪声配方/频率/振幅/形态曲线）
- 核心区（权重>0.7）：纯类型，不被稀释
- 过渡区：较宽（数十格）的 lerp 渐近过渡，避免悬崖
- **不是"所有类型一起搅"，也不是"每个点在几个类型间混"**

### 类型决定绝对高度（地理学正确）

- 平原低、山脉高、高原中高平顶——真实地理
- TerraForged 式"所有类型一个范围"不符合用户要求
- 各类型输出范围：PLAIN [0.01, 0.05], HILLS [0.04, 0.18], PLATEAU [0.22, 0.58], MOUNTAINS [0.25, 0.82]
- 但本类型内部**在范围内有丰富变化**（不是固定值）

### 真实世界对照示例

| 示例 | 地形类型 | 特征 |
|------|---------|------|
| 北美大平原 | PLAIN（craton省主导） | 极度平坦、一望无际、可建造 |
| 洛基山脉 | MOUNTAINS（belt省主导） | 蜿蜒山脊、尖峰、foothill渐升 |
| 科罗拉多高原 | PLATEAU（plateau省主导） | 平顶台地、边缘陡崖下降 |
| 盆地山脉省 | BASIN/HILLS（craton+basin） | 山谷交错、内凹洼地 |
| 阿巴拉契亚 | MOUNTAINS（craton边缘） | 古老圆顶、低缓起伏、不是尖峰 |
| 喜马拉雅 | MOUNTAINS（belt省, 高wBelt） | 尖峰、褶皱山系、极高 |
| 青藏高原 | PLATEAU（plateau省主导） | 高海拔、平顶、边缘陡变 |
| 塔里木盆地 | BASIN（basin省主导） | 内陆洼地、沙漠覆盖 |

### 通用规则

```
MOUNTAINS ≠ 一个噪声
MOUNTAINS = {
    belt省主导：脊线山（warp + ridge pow）
    plateau省边缘：阶梯陡崖山
    craton省：圆顶老山
}
```

## 八、地形类型系统最终修复（2026-07-15晚）

### 问题
用户报告三个问题：
1. 类型间悬崖（过渡区仅1格，相邻cell不同类型产生100+块悬崖）
2. 类型内部单调（每个类型只有一种FBM，没有按省上下文分化）
3. warp错误（强度12+hash2离散，破坏连续性）

### 修复方案（三层分离架构）

#### 1. TypeMorphology 丰富化
- **删除错误 warp 方法**：移除 `hash2` + 强度12的warp，避免离散跳变
- **山脉内部多样性**：按省上下文分化三种形态：
  - belt省主导 → 脊线山（`pow(|r|,k)` + belt warp）
  - plateau省主导 → 阶梯陡崖山（平顶+边缘陡崖）
  - craton省主导 → 圆顶老山（低缓起伏）
- **Peak 按省分化**：belt省→极尖峰，plateau省→平顶高峰
- **平原/丘陵删除 warp**：直接使用原始噪声，保持连续性

#### 2. TerrainComposer 样条过渡
- **替换 smoothstep**：使用 `NoiseUtil.spline`（Catmull-Rom样条）实现C1连续过渡
- **过渡区间**：控制点 [0.0, 0.3, 0.7, 1.0]，过渡区宽度0.4权重空间（≈25格）
- **消除悬崖**：相邻类型渐近过渡，不再1格硬切

#### 3. 扫描 Ridge 残留
- **Ridge.java 存在但未使用**：LandShape 注释明确"禁用零交叉 Ridge"
- **TerrainParams.beltRidgePower**：已废弃，引擎不读取
