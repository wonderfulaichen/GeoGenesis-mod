## 四、需要补的合规动作（可执行）

> The above copyright notice and this permission notice shall be included in all copies

   ```text
   This project contains code derived from the following third-party projects.

   yardsite
   Copyright (c) 2026 CYun_CYER
   Licensed under the MIT License. Full text below.

   Derived portions: client/preview/** (ProgressiveSampler, SandboxShade,
   SandboxRasterizer, SandboxGeometry, TerrainFieldData, ViewTransition,
   SandboxLod, TerrainViewMode, PreviewDisplay), client/reveal/**.

   <MIT 全文，逐字节照 参考/sources/yardsite/LICENSE>
   ```
2. **随 jar 分发**：放进 `forge-1.20.1-47.4.10-mdk/src/main/resources/META-INF/THIRD-PARTY-NOTICES.md`
   （该目录已存在，且会进 jar）。源码交付时根目录那份即可。

4. 本项目总许可保持 **All Rights Reserved** 不变；上表只是**新增第三方声明**，不改变总许可。

## 五、仍未核实（不得当成已核清）

1. **引入版本不可复现**：`参考/` 被 `.gitignore` 忽略，两个参考目录**都没有 `.git`**
   ⇒ 无法用提交号证明我们照的是哪一版；本文件只能给出版本快照的文件行数与 LICENSE 哈希。
   若上游后续改许可，本记录**自动失效**，须重新取一次。
2. **yardsite 自身的历史来源未核**：它的 `src/**` 无任何版权/许可行，根 LICENSE 只有 2026 CYun_CYER
   一条 ⇒ 无法排除其中含更早的第三方片段（与 FreeTerraForged 那批同样的风险，
   见[新版地形第三方许可核查 §本地上游逐文件证据](新版地形第三方许可核查.md)）。
3. **`_archive/` 未逐文件核**：`_archive/` 下归档的旧渲染/预览代码可能也含 yardsite 派生片段，
   本轮未逐一比对。归档物不进 jar，但进源码包。
4. **未做相似度鉴定**：本核查依据的是**我们自己的注释自述 + 上游文件存在性**，
   没有做逐 token / 逐字节比对，也没有做编译闭包或 SBOM。
5. **落成动画的暂停状态可能变化**：一旦 `-Dgeogenesis.reveal.enabled=true` 成为默认或功能恢复，
   派生面与分发面都会扩大（`client/reveal/**` 从"死代码"变"活跃代码"），声明义务不变但审计须重做。
6. **探针目录**（`src/diagnostics/**`）随源码分发，其中 3 个文件含上游对拍说明；本轮只登记不裁剪。
7. **`参考/sources/` 其余目录**（`MOBIDICpy-main`、`novoatlas-ref`、
   `Realistic-Terrain-Generation-Plus-main`、`worldgen-master`、`骨架侵蚀参考项目`）
   **不在本次核查范围**。它们是否被引用过，需按同样方法另开一轮，不能默认"没用过"。
