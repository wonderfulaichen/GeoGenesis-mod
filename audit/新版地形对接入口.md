## 避免接错

- `CoherentMorphWorld()` 无参入口和 `CoherentMorphWorld(seed)` 使用默认零偏移分布，**不是** +0.30 候选；请以第 1 项的显式构造为准。旧 S3 图与入口保留作对照。
- 生产游戏目前仍由 [GeoGenesisGenerator.java](../forge-1.20.1-47.4.10-mdk/src/main/java/com/geogenesis/worldgen/generator/GeoGenesisGenerator.java#L699-L735) 调用 [GeoGenesisTerrain.java](../forge-1.20.1-47.4.10-mdk/src/main/java/com/geogenesis/worldgen/terrain/GeoGenesisTerrain.java#L462-L492)，包括既有侵蚀和水文。这不是当前新版候选的完整输出。
- 新版源码在 Gradle 独立 `diagnostics` 源集，相关类多数为包内可见，存在反射及实例内可变缓存；它不是为其他游戏准备的公开库，也未证实同一实例可并发共享。当前显式上下文支持多个 seed；旧 `original()` 路径仍仅适用于正典 seed。
- 修复后的构造驱动仅做了独立传播实验，**尚未接到新版高度**；当前导出也不包含生产水文、侵蚀、洞穴、地层、群系和 Minecraft 方块/结构。

## 样本的准确口径

固定 seed `9139912035078620160`，1401×1401、步长 5 块，原点 `(-3642.5, -3365.5)`，海平面参考值 63；Y 使用 `TerrainParams.defaults()` 及高度范围 -64..320，并非读取朋友或游戏运行时配置。数据是采样数组而非 Minecraft 方块、现成高度图格式或实时接口：`height.f64be`、`e.f64be`、`sea-weight.f64be` 为大端 float64；`type.u8`、`active.u8`、`winner.u8`、`side.u8` 为字节数组；`cells.i64be` 为大端 64 位格子键。按导出器逐行 z、逐列 x 的顺序存放，元数据与剖面包含在 ZIP 中。

### 复现路径（历史命令，不是已验证的新克隆教程）

- 完整原始命令和运行环境分别见 [commands.json](../handoff/attachments/m1a-m1b-20261101/commands.json)、[environment.json](../handoff/attachments/m1a-m1b-20261101/environment.json)。历史环境为 Windows、Temurin Java 21.0.11、`-Xmx3g -Dfile.encoding=UTF-8`，未设置 `geogenesis` JVM 属性。Gradle wrapper 位于 `forge-1.20.1-47.4.10-mdk`，历史执行 `gradlew.bat --offline --no-daemon --console=plain compileDiagnosticsJava`；`--offline` 依赖已有本机 Gradle/Forge/Minecraft 缓存，新克隆尤其是空缓存不能假设成功，需要可获取构建依赖的环境。新克隆构建、联网获取与依赖闭包本次均未验证。
- `M1ThresholdHeightGallery` 需要两个参数：**已有冻结输入目录**和**不存在的输出目录**。输入至少包含 `type.u8`、`side.u8`、`cells.i64be`；导出器逐像素校验几何键和海陆/陆地类型，不能以任意同尺寸数据代替。仓库已跟踪的 [raw-data.zip](../handoff/attachments/land-threshold-shift030-20261101/raw-data.zip) 中存在 `shift030/local/` 这些文件；历史命令使用的是 `build/m1a-m1b/threshold-frozen/shift030/local`。两者是否逐字节相同及用 ZIP 提取数据重新完整生成，本次**未验证**。输出父目录须存在，输出目录本身不得存在；请使用独立新路径，勿覆盖现有实验。
- Java 命令的类路径不是 `classpath.txt` 可直接复制：历史 [classpath.txt](../handoff/attachments/m1a-m1b-20261101/classpath.txt) 含本机 `D:\\.gradle` 绝对路径和 `build/terrain-upgrade/baseline` 等构建产物。必须在目标机器正确构建并解析 diagnostics 运行时类路径，确认 baseline 条目实际来源与必要性，再运行 `com.geogenesis.worldgen.terrain.candidate.M1ThresholdHeightGallery <冻结输入目录> <新输出目录>`；当前未提供经新克隆验证的一键类路径生成步骤。历史记录的全量 check 还需对应冻结数据，不能把已有日志当新环境 PASS。

### 文件格式及建议纳入提交

每个数组没有文件内维度头：以 `meta.json` 为准，本样本每个 `u8` 为 1,962,801 字节，每个 64 位数组为 15,702,408 字节；`x = -3642.5 + 5 * 列`、`z = -3365.5 + 5 * 行`。`type` 是加权主导配方而非 `winner`；`active` 为参与配方数；`winner` 是最终区域赢家，`side` 是其陆海分类（0 陆、1 海），不等价于 `height < 63` 或实际水方块。`sea-weight` 是海洋配方权重和，`e` 是映射前连续值，`cells` 为几何格子键；`profiles.csv` 列为 `line,x,z,e,y,distance`。语义与 ID 映射依赖对应版本源码，不能当作长期稳定协议。

建议由负责代码的代理确认后，将两处必要源码修改、`M1ThresholdHeightGallery.java` 和 `M1ThresholdHeightCheck.java`，以及本页和许可核查纳入同一可审阅版本；如需复现 A/B 图，再审阅纳入渲染脚本及其依赖、M1 原始样本和验证记录。冻结输入 ZIP 已跟踪；旧 S3 基线、类路径生成、全部传递依赖、第三方声明及大文件分发策略仍须逐项核实，**不是已经完成的提交清单**。若只交付样本，可优先明确许可并提供 ZIP、元数据、哈希及格式说明，但不代表能从源码复算。不要未经另一代理确认提交其进行中的工作；本任务不提交、不推送。
