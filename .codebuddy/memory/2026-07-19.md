## 夜间（二）：滚动修复 + 三面板 UI 精修

### 根本问题诊断
旧方案用 `GuiGraphics.pose().translate(0, -scroll, 0)` + mouse 手动 `my + scroll`，导致 ParamSlider 等内建 Widget 的 isMouseOver/getY 与实际渲染坐标错位，滑块无法点在正确位置。

### 解决
- **放弃 translate**：ConfigScreen 不再用 pose().translate()
- **scrollOffset 注入面板**：每个面板存 `scrollOffset`，所有 Y 计算统一用 `top() = baseY - scrollOffset`
- **鼠标事件直接传原始坐标**：面板内鼠标方法不再手动加 scroll（内部 top() 自动偏移）
- **ConfigScreen**：滚轮/切页签时 `pushScrollToPanels()` 同步 scrollOffset

- 交替行背景优化
- 行高 56px（更宽敞）

### ParameterConfigPanel 精修
- 「▸ 基础参数」标题 + 9 个紧凑行
- 3 个折叠段（世界高度/雪线/尺度）统一用 `renderSection` 方法
- MixerPanel 预设 `setContentHeight` 使 getHeight 正确
- 所有 Y 用 `top()` 滚动偏移

### ConfigScreen 重构

- 增加 `pushScrollToPanels()`

### 三个问题根因

1. **海洋无法配置**（含"数值不是设计好的"）
   - 根因：海洋类型用 `readOnlySlot`（loSetter=null/hiSetter=null），滑块 `active=false`
   - 设计上所有 9 类型都可自由配置（每类型 2 控制点 = 共 18 个独立参数）
   - 修复：用 `oceanSlot(prevDepthCfg, depthCfg)` 代替 `readOnlySlot` → lo + hi 都有 getter/setter
   - 深海 lo=-1 固定（prevDepthCfg=null），海岸 hi=0.02 固定（depthCfg=null），其余 6 个滑块全部可调
   - 浅海 lo 绑定到 `deepOceanDepth`（= 深海 hi 同步），大陆架 lo 绑定到 `shelfDepth` 等

2. **滑块和图表不联动**
   - 根因：文件锁修复后联动逻辑也丢失了（slider onChange 是 noop，控制点 release 不通知滑块）
   - 修复：完整双向同步链路
     - 拖动滑块（per frame）：onChange 调 `chart.refreshFromConfig()`（控制点实时跟随）
     - 释放滑块（only once）：onValueCommitted 写 config + 调 `chart.refreshFromConfig()` + 触发 onMarkDirty
     - 释放控制点（only once）：onControlPointCommitted 调 `chart.refreshFromConfig()` + 同步所有滑块 `setCurrentValue` + 触发 onMarkDirty

3. **数值不是设计好的**
   - 根因：海洋 lo/hi 使用 loc+ depth 而非 eLand 范围。但原始设计（05 号文档）明确 X 轴为 e[-1,1]（eLand），滑块值是 eLand 范围。海洋 eLand 范围由 depth 派生（lo=prevDepth, hi=depth）。文档无 loc 语义。
   - 当前修复保持 eLand 范围语义（滑块值 = eLand 可调），与设计文档一致

### 设计约定（v5 新增）
1. **所有 slot 都可配置**：海洋用 `oceanSlot(prevDepthCfg, depthCfg)`，陆地用 `interactiveSlot(centerCfg, halfRangeCfg)`
2. **双向联动**：拖动 → `chart.refreshFromConfig()`（图表视觉更新，不写 config）；释放 → 写 config + 触发预览
3. **钩子模式**：ParamSlider 加 `onValueCommitted`（release 时触发的 Runnable），DualRangeChart 加 `onControlPointCommitted`（控制点 release 时触发）
4. **不降级渲染性能**：控制点拖动时不调 chart.refreshFromConfig（已缓存位置），只滑块拖动时调

## 清晨 v6：联动实时性 + 滑块范围修复

用户报 3 个新问题，**BUILD SUCCESSFUL in 33s**。

### 三个问题根因

1. **参数区间怎么只有0~1**
   - 根因：`makeSlider` 中 `minSl = isOcean ? -1.0 : 0.0` —— 陆地范围 [0, 1]
   - 设计文档（05）明确 X 轴 e[-1,1]，所有 9 类型滑块都应支持完整 [-1, 1]
   - 修复：所有滑块范围统一 `[-1.0, 1.0]`

2. **联动不是实时和图表联动**
   - **核心根因**：MC `AbstractSliderButton.onClick` 只设 `value` 字段，**不调 `applyValue`**
   - 我的 ParamSlider.mouseDragged 只调 `onClick`，没调 `applyValue()` → onChange 拖动期间不触发 → chart 不刷新
   - 同样 DualRangeChart.mouseDragged 之前不通知父组件
   - 修复：
     - `ParamSlider.mouseDragged` 显式调 `this.applyValue()`（每帧触发 onChange）
     - `DualRangeChart.mouseDragged` 每帧调 `onValueChanged` 回调（visual only，不写 config）
     - `DualRangeChart` 加 `getDraggingSlotIndex/isDraggingHi/yToEForDragging` 查询方法

3. **深海与浅海联动 bug**
   - 设计上：海洋 lo=prevDepth, hi=depth，**相邻 slot 共享同一深度值**（如 深海 hi 和 浅海 lo 都 = deepOceanDepth）
   - 拖动时 setter 不调（防文件锁），所以关联滑块视觉不同步
   - 修复：TerrainConfigPanel 构造器中订阅 `chart.onValueChanged`，根据拖动 slot 索引同步关联滑块
     - 深海 hi 拖动 → 同步更新 深海 hi + 浅海 lo
     - 浅海 lo 拖动 → 同步更新 浅海 lo + 深海 hi
     - 同理 浅海 hi ↔ 大陆架 lo，大陆架 hi ↔ 海岸 lo

### 设计约定（v6 新增）
1. **MC 滑块陷阱**：`onClick` 不触发 `applyValue`/`onChange`，拖动期间必须**显式**调 `applyValue()` 才能联动
2. **拖动期间双套回调**：`onValueChanged`（每帧，visual only） vs `onControlPointCommitted`（release，写 config + markDirty）
3. **海洋耦合是设计**：相邻海洋类型共享深度值（深海 hi=浅海 lo=deepOceanDepth），联动回调是必要的
