## 深夜2：修复 Voronoi 断裂——共享噪声基底

### 根因

旧 Voronoi 方案让每个类型用**完全独立的噪声种子和结构**（PLAIN=seed 300, MOUNTAINS=seed 302-304），边界处通过高斯权重混合独立噪声输出。但两个独立噪声的频谱不同，混合后仍频谱突变，产生可见断裂。

### 参考模组的正确做法

TerraForged / ReTerraForged 的关键设计：
1. 所有地形类型共享同一个噪声函数结构（Perlin + Warp）
2. 类型间仅通过**参数（振幅/偏移）**区别
3. 边界处混合的是**参数，而非噪声输出本身**
4. 使用二次衰减 `weight = (1-δ/R)²` 而非高斯加权

### 修复内容

**TypeGenerators.java** — 彻底重写
- 删除 10 个独立噪声节点 + 5 个独立生成器方法
- 替换为：1 个共享 FBM 噪声（域扭曲 3 层）+ 类型范围常量 + 小幅类型细节
- 新增 `computeSharedNoise(wx,wz)` + `getTypeLo/Hi(tc)` + `computeDetail(wx,wz,type,alpha)`

**VoronoiRegionField.java** — 彻底重写
- 高斯距离加权 → TerraForged 风格二次衰减 `weight²`
- 新增 `sampleBlend()` → 返回混合后的 (lo, hi, dominantType, alpha)
- 混合对象是范围参数，不是噪声输出

**TypeLandShape.java** — 彻底重写
- `sample()` = regions.sampleBlend() → 共享噪声 → `lerp(lo, hi, noise)` → +detail

### 数学保证

```
共享噪声 f(x,z) = 连续 Simplex 3 层 + 域扭曲 → ∈ [0,1] 连续
范围参数 lo(x,z), hi(x,z) = 二次权重混合 → C1 连续
eLand = lo + (hi-lo) × f(x,z) → 连续 × 连续 = 连续 → 无断裂
细节 d(x,z) × alpha(x,z) → 边界处被衰减到 0
```

`gradlew compileJava --rerun-tasks` → **BUILD SUCCESSFUL in 17s**

## 深夜4：修复"细胞网格状亮点"——域扭曲空间距离场

### 截图反馈

用户截图显示：图中**规则的亮斑按 cell 间距排列**（红色椭圆标注），整张图呈 cell 周期性图案。

### 根因（深入研究后）

v3 实现的问题不在"混合"本身，而在**距离场计算的位置**：
- 距离计算在**原始 (wx, wz) 坐标**上进行
- cell 中心是 `(cx + 0.45*jitter) * 400` 的**规则格点**
- 即便用高斯权重 `1/d^p` 平滑，每个 cell 中心位置仍是"距离极小值"→ 形成规则亮斑
- 域扭曲只对 `computeSharedNoise` 起作用（150 强度），**不影响距离场本身**

参考项目（TerraForged）的正确做法（已读源码确认）：
1. **距离场也在域扭曲空间计算** —— 在 `(wx + warp*noiseA, wz + warp*noiseB)` 上找 cell
2. **warp 强度 ≫ cell 间距/2** —— TerraForged scale=800, warp=320（40%）
3. **高斯权重 `exp(-d²/2σ²)` 取代 `1/d^p`** —— 权重连续平滑，无锐利中心
4. **cell 内采样 perlin 不用 cell 距离** —— cell 距离只作权重，不直接当高度

### 修复

**VoronoiRegionField.java — 域扭曲空间距离场**
- 新增 `WARP_AMP=250`、`SIGMA=200`、`SEARCH_RADIUS=1`（3×3 = 9 cells）
- `sampleBlend`：先 warp (wx, wz) → 在扭曲空间找 3×3 cell → 高斯权重
- `dominantType`：同样用扭曲空间
- 抽离 `CELL_SPACING=400` 常量（消除硬编码）

**TypeGenerators.java — 增强 warp**
- `warpAmp` 150 → 300（参考 TerraForged `scale/2.5=320`）
- 所有 4 个频率中前 3 个（low/mid/high）都用扭曲后坐标
- 超高频（detailFreq 1/50）保留原始坐标——细节不应被扭曲

### 数学保证

| 变量 | 连续性 | 来源 |
|------|--------|------|
| warped 坐标 | C∞ | warp 噪声在原始坐标计算（连续函数）|
| cell 中心位置 | C∞（跨空间） | 扭曲空间 cell 中心在原始空间被噪声扰动 |
| 高斯权重 | C∞ | exp(-d²/2σ²) 处处连续 |
| blended lo/hi | C∞ | 9 cell 连续 × 9 cell 连续 + 归一化 |
| 共享噪声 | C∞ | 4 频率共享 + warp 300 |

## 凌晨5:30 — 每类型独立噪声配方（参考 TerraForged/RTG/ReTerraForged）

### 问题反馈

用户反馈"不断裂了，但不同类型的地形没实现"。确实，旧代码所有类型共用同一套 4 频率 FBM 噪声，只有 lo/hi 范围不同 → PLAIN 只是缩小的 MOUNTAINS，视觉无差异。

### 参考项目研究（三个项目都读了）

发现关键架构差异：
- **参考项目**：每种地形类型有**独立噪声配方**（不同种子、频率、运算符组合）
- **我们**：所有类型共用同一套 FBM

TerraForged 每种类型构建独立 Module 树：MOUNTAINS 用 Ridge+Valley+CellEdge，PLATEAU 用 Terrace，HILLS 用 Billow+Warp，PLAINS 用极低振幅 Perlin，BASIN 用 Invert。

### 实现：TypeNoiseProvider.java（新增）

创建 `TypeNoiseProvider.java` —— 5 个陆地类型各有独立噪声节点树，利用已有的 `Ridge/Billow/Terrace/Warp/Invert/Map` 等噪声运算符。

| 类型 | 配方 | 视觉特征 |
|------|------|---------|
| PLAIN | Map(Simplex x/500 → [0.40,0.60]) | 极平坦 |
| HILLS | Map(Warp(Billow x/250 + det)) | 圆润起伏 |
| MOUNTAINS | Warp(Ridge x/400, 200) + 0.3×Ridge x/120 | 尖锐脊线 |
| PLATEAU | Terrace(Map(x/350), 5步, 0.7smooth) | 阶地台地 |
| BASIN | Map(Invert x/300 → [0,0.6]) | 凹陷盆地 |

### TypeLandShape 流程变更

旧：`base = computeSharedNoise(wx,wz)` → 所有类型用同一噪声值

新：`for each land type: base += weight × typeNoise.computeNoise(type, wx, wz)` → 各类型独立噪声按权重混合

cell 边界处 typeWeights 连续过渡各类型的噪声，保证无断裂。

## 凌晨6:00 — 修复 PLATEAU 的 Terrace 整图切沟问题

### 用户反馈

游戏截图显示：图中**大量水平横向"沟"**（红色椭圆标出），整张图呈台阶状切片。用户问"参考项目是这么写的？"

### 根因

v5.1 用 `Terrace(Map(Simplex(x/350)), 5, 0.7)` 作为 PLATEAU 噪声配方，结果：
- `Terrace` 用 `floor` 量化噪声为 5 级台阶
- strength=0.7 → 输出 70% 量化值 + 30% 平滑
- **PLATEAU 只占 15% cell，但 cell 边界 typeWeights 混合把 plateau 噪声带进相邻 HILLS/PLAIN 区域**
- 跨 cell 时高度出现 0.04 eLand（~10 块）跳变 → 满图横纹

### 参考项目实际做法（再读源码确认）

- **TerraForged `badlands`**: 用 `Steps(4, slope_min=0.65)` 恶地专用
- **TerraForged `mountains_3`**: `AdvTerrace(24 steps, mask, modulation)` 山区专用
- **TerraForged `plateau`**: 用 `Terrace(4 steps, blend_range=0.4, cliff=0.15, ramp=0.9)` — 平台边缘用台阶，中央平滑
- **RTG `VoronoiPlateauEffect`**: Voronoi 细胞值 + 简单 `stepIncrease(start, finish, height)` 只在 0.25~0.4 边缘作平台效应
- **关键点**：参考项目的 Terrace 都不是"满图切台阶"，而是**只在局部（恶地/山脊/平台边缘）使用**

### 修复

**TypeNoiseProvider.java** — PLATEAU 改为极低频 3 层叠加 + 窄范围，无硬台阶：
```java
Noise platBase = new Frequency(new Simplex(420), 1.0 / 500.0);   // 极低频骨架
Noise platMid  = new Boost(new Frequency(new Simplex(421), 1.0 / 200.0), 0.25);
Noise platDet  = new Boost(new Frequency(new Simplex(422), 1.0 / 60.0), 0.08);
platNoise = new Map(new Add(new Add(platBase, platMid), platDet), -1.5, 1.5, 0.30, 0.70);
```
- 极低频 1/500 主导 → 宽阔大特征（500 块一个波）
- map 范围窄 [0.30, 0.70] → 平台感
- 不用 Terrace → 无任何硬台阶
- 视觉上 PLATEAU 是"中高度缓坡高原"，与 PLAIN（低平）/HILLS（圆润）/MOUNTAINS（尖脊）有清楚区别

## 深夜2 — v6.0 三大问题综合修复（参考 TerraForged 源码研究）

### 问题
1. 断裂线差 1 格：Voronoi 边界高度离散跳变
2. 高原像悬崖：PLATEAU 无边缘过渡，直接从平原拔起
3. 丘陵"等高线"状：单层 Warp 无法破除 Billow 等高线结构

### 参考研究
深入读了 TerraForged 源码：
- **TF TerrainBlender**: 用 `borderDistance²` 平方衰减权重
- **TF plateau.json**: `ramp_height=0.35`（35% 平滑过渡）
- **TF hills_1.json**: 双层 Warp（distance=20 + distance=200）+ `Perlin×Billow^0.5`

### 修复内容

#### 修复 A：断裂线差 1 格
**根因**：`TypeLandShape.sample` 用 `eLand = blend.lo + range*base` 在 cell 边界 lo/hi 离散切换，导致 1 块高度差。
**修复**：
- **TypeGenerators.java**：新增 CENTER/HALF_RANGE 模式（`PLAIN_CENTER=0.0375, PLAIN_HALF_RANGE=0.0225` 等）+ `getTypeCenter/getTypeHalfRange` 方法
- **TypeLandShape.java**：改为按 typeWeights 直接加权混合各类型独立 eLand：`eLand = Σ(w_i × (center_i + halfRange_i × (2×noise_i−1))) / Σw_i`，消除 lo/hi 离散跳变

#### 修复 B：PLATEAU edge ramp（参考 TF ramp_height=0.35）
**新增**：
- `platShapeNoise` = Map(Frequency(Simplex(437), 1/1000), [-1,1]→[0,1]) 大尺度 shape mask
- `computePlateau(wx, wz)` = noise × smoothstep(shape, 0.15, 0.40) + 0.08 × (1−edge)
- 边缘平滑降至 0.08（近平原），中心全高原高度

#### 修复 C：HILLS 双层 Warp + Perlin×Billow^0.5（参考 TF hills_1.json）
**替换旧噪声**为：
- Perlin(1/500) × Power(Billow(1/300), 0.5) → Warp(distance=20, freq≈1/30) → Warp(distance=200, freq≈1/333) → Boost(0.6) + Bias(0.02) → Clamp(0,1)
- 利用了 `Multiply`, `Power`, `Clamp`, `Constant` 噪声节点
