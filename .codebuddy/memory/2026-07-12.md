## 海岸平台感根因深度分析（2026-07-12 v2）
- 用户反馈：v1 改动（COAST_SUB 0.20, 水滴门槛 seaNorm-0.15, 回填抑制带 0.02）完全无效。
- 根因重新分析：平台感由**两层硬边界**共同造成：
  1. `CellGenerator.landHeight()` 在 c=0 处返回 NaN（`if (c < 0.0) return Double.NaN`）→ 所有河流在大陆性噪声 c=0 处强制终止。
  2. 近岸地形极端平坦（`blendE` 在 c∈[0,0.15] 区间 e≈0.001~0.03），水滴失去坡度动力（`vlen < 1e-12f` → return）。
  3. `carveRivers` 海平面地板（`floorC = seaNorm - COAST_SUB * ...`）在远离海岸处限制下切深度。
- 修复方案（已确认执行）：
  1. `landHeight()` NaN 阈值放宽：`c < 0.0 → NaN` 改为 `c < -0.30 → NaN`（性能优化）+ `e < -0.05 → NaN`（允许浅海参与侵蚀）。
  2. `HydraulicErosion` 常量微调：`COAST_SUB` 0.20→0.25（河口允许冲刷到海平面以下0.25），`COAST_RANGE` 0.40→0.50（冲刷过渡范围扩大）。
- 编译通过（BUILD SUCCESSFUL）。待 runClient/runPreview 目检。

## 海洋深度根因修正 v4（2026-07-12 v4）

  1. `CellGenerator.blendE`：移除 `HEIGHT_C/HEIGHT_E` 中间样条，海洋侧 `e = c`，陆地侧 `e = eLand`。

  3. `GeoGenesisConfig`：同步修改默认值。
  4. 删除 `run/config/geogenesis-common.toml` 让新默认值生效。
- **预期效果**：大陆架收窄（约 84 格），浅海深度增加（25 格），平台感消除。

## 海底侵蚀痕迹修复（2026-07-12）
- **问题**：截图显示海洋底部有河流侵蚀的痕迹（沟壑、树枝状图案），这是因为河流侵蚀系统在海洋区域没有正确停止。
- **根因**：
  1. `CellGenerator.landHeight()` 返回 e 值，海洋区域 e < 0 但未被正确过滤，导致海洋区域参与侵蚀。
  2. `HydraulicErosion.simulateDrop()` 水滴生成门槛过于宽松（`baseH <= seaNorm - 0.15f`），允许海平面以下区域生成水滴。
  3. `simulateDrop()` 水滴流动遇到海洋区域（h < seaNorm）未停止，继续侵蚀海底。
  4. `carveRivers()` 河口冲刷逻辑允许河谷低于海平面，导致海底侵蚀痕迹。
- **修复**：
  1. `CellGenerator.landHeight()`：`c < -0.30 → NaN` 改为 `c < 0.0 → NaN`，海洋区域完全不参与侵蚀。
  2. `HydraulicErosion.simulateDrop()` 水滴生成门槛：`baseH <= seaNorm - 0.15f` 改为 `baseH <= seaNorm`，仅陆地生成水滴。
  3. `simulateDrop()` 水滴流动：添加 `if (h0 < seaNorm) return;`，海洋区域停止流动。
  4. `carveRivers()` 河口冲刷：`floorC = seaNorm - COAST_SUB * ...` 改为 `floorC = seaNorm`，河谷下切不低于海平面。
  5. `smoothErosionResult()` 回填逻辑：海平面以下不回填，避免海底侵蚀痕迹被抹平。

## 海洋深度架构纠正 v5（2026-07-12 v5，对齐原版 offset.json 单条样条）

  5. `GeoGenesisConfig`：同步修改默认值。
  6. 删除 `run/config/geogenesis-common.toml` 让新默认值生效。
- **预期效果（c=-0.1，约167格离岸）**：

- **原方案漏洞（已否决）**：初版计划把侵蚀高度场转到归一化 [0,1] 空间。经核查该空间梯度比当前 e-space 更小（大陆架在归一化空间只占 ~0.12 vs e-space 0.25），水滴加速更慢、河口更短 → **会加重大陆架平台感，与目标相反**。
- **正确方案**：侵蚀高度场改用**抽象方块高度**（经 `HeightCurve` 封装，核心零 MC import），既保留物理坡度梯度（水滴顺坡加速、河口自然延伸入海，对齐备份物理侵蚀观感），又符合解耦原则（`HeightCurve` 是唯一 MC 边界适配器）。
- **改动 5 文件**：
  1. `HeightCurve`：新增 `heightF(e)`（float 不取整，梯度靠相邻差需亚方块精度）+ `eFromHeightF(y)`（二分逆解；height(e) 在 [-1,1] 单调增、海岸 e=0 连续，二分有效）+ `seaLevel()/mountainCap()` 访问器。
  2. `RiverField`：构造器 `worldHeightBlocks` → `HeightCurve hc`；`computeRegion` 高度场 `h=hc.heightF(e)`（陆地/近岸海洋），预计算 `seaNormY=hc.heightF(0)`、`heightScale=mountainCap-seaLevel`；回写 `carvedE=hc.eFromHeightF(h)`、`lakeLevel=hc.eFromHeightF(lr.level())` 逆映射回 e-space（维持 carvedE/baseE/landMask 等 e∈[-1,1] 契约）；`TileLakeSolver` 传 `seaNormY` 作海洋哨兵。
  3. `HydraulicErosion`：构造器收 `heightScale`；`COAST_SUB/SMOOTH_DEPTH_BAND/0.25f 陆地细节带` 由 e 单位 ×heightScale 等比放大为方块单位；`ERODE_LARGE/FINE` 等**无量纲速率不乘**（梯度 dh 已自带 ×heightScale，否则过侵蚀）；`estuaryDepth/riverValleyDepth` 由 RiverField 按 ×heightScale 传入。
  4. `TileLakeSolver`：去掉 `worldHeightBlocks`；输入为方块高度场，深度=`filled-height`（已是 block），`eps=0.5`；NaN 海洋哨兵改设为 `oceanLevelY`（原 e-space 以 0=海平面，对应方块海平面）。
  5. `GeoGenesisTerrain`：构造 `new RiverField(seed, cellGen, riverSettings, new HeightCurve(params))`。
- **正确性要点**：e-space 刻蚀深度相对地形被等比保留（valleyDepth 0.06 e ≈ 0.06×192≈11.5 block，carvedE 仍降 ~0.06 e）；差异在于物理梯度令水滴真正顺大陆坡加速、河口连贯延伸入海。下游（BiomeClassifier/Preview/writeRiverFields）全部基于 e-space，契约不变。

- **经验**：①归一化 [0,1] 不等于"更大梯度"，梯度取决于坐标单位跨度，纯数学归一化会缩小物理坡度；②侵蚀核心做 MC 解耦时，让 `HeightCurve` 同时承担"e↔抽象高度"双向换算，核心只持抽象坐标，比直接注入 MC minY/maxY 更干净。
