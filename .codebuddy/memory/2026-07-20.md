## 箭头 Y 坐标显示修复

**问题**：箭头数值（↓/↑）显示错误的 Y 坐标。海洋类型（e<0）使用了陆地公式 `seaLevel + e * (maxY - seaLevel)`，导致 Y 坐标错误。

```java
chart.setEToWorldY(e -> {
    if (e <= 0.0) return seaLevel - (-e) * (seaLevel - minY);
    else return seaLevel + e * (maxY - seaLevel);
});
```
