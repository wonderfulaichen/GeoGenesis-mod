## PreviewDisplay 图例覆盖 Bug 修复

用户反馈：预览窗口上方出现大片棕色区域，遮挡控件。
根因：`PreviewDisplay.drawLegend` 中 `GuiGraphics.fill` 使用 `fill(x, y, width, height)` 语义，但 1.20.1 该方法实际为 `fill(x1, y1, x2, y2)` 坐标形式。连续图例渐变条写成 `fill(bx, by+i, bw, 1, ...)` 导致从 `bx` 到 `x=12` 的水平条铺满整个预览；离散图例背景写成 `fill(lx-4, ly-4, panelW, panelH, ...)` 导致从右侧图例位置到 `x=128` 的大矩形覆盖整个上半屏，叠加在控件与地图之上，呈现棕色。
修复：
- 连续图例：`fill(bx, by+i, bx+bw, by+i+1, ...)`，仅绘制 12px 宽右侧渐变条。
- 离散图例：`fill(lx-4, ly-4, lx-4+panelW, ly-4+panelH, ...)` 与 `fill(lx, cy, lx+10, cy+10, ...)`，使用坐标终点。
- 增加 `showLegend` 开关与 `toggleLegend()`，并在 `GeoGenesisConfigScreen` 绑定 `L` 键切换，避免图例始终遮挡地图。
- 编译验证：`gradlew.bat clean compileJava --offline` 通过（BUILD SUCCESSFUL）。
