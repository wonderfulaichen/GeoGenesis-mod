## 纠正：ForgeRegistries.BIOMES 同步时机 → ServerLifecycleHooks 方案

- 初版修复用 `ForgeRegistries.BIOMES.getHolder(key)` 又崩溃（"minecraft:plains not registered"@ createLevels → createBiomes）。
- **根因**：`ForgeRegistries.BIOMES` 是 Forge 的静态注册表包装，在世界生成初期（`createLevels`→`createBiomes`）尚未从当前世界的 dynamic 注册表同步数据，故 `getHolder(plains)` 返回 empty → 抛 `IllegalStateException`。
- **最终方案**：优先使用 `ServerLifecycleHooks.getCurrentServer().registryAccess().registryOrThrow(Registries.BIOME).getHolder(key)`。Forge 在 `MinecraftServer` 构造期即 `setCurrentServer(this)`，早于 `runServer`→`initServer`→`createLevels`→`createBiomes`，故此时 RegistryAccess 已含完整 dynamic biome 注册表。
- 首次成功解析时缓存 `Registry<Biome>` 到静态字段，后续调用复用（稳健）。
- 兜底：无服务器时仍试 `ForgeRegistries.BIOMES`（客户端/晚于同步的路径）。
- runClient 目检（待做）。

## 创建世界卡死在 0%：ConcurrentHashMap 死锁 + 竞态

- **现象**：19 个 Worker 线程各自打印 "terrain engine initialized" 后日志终止，无 crash 但进程冻结。
- **根因 1（致命）**：`GeoGenesisTerrain.generateChunk` 末尾 `if (cache.size() > CACHE_SIZE) { cache.keySet().iterator().remove(); }`——该函数是 `cache.computeIfAbsent(key, k -> generateChunk(...))` 的 lambda。ConcurrentHashMap 的 `computeIfAbsent` 禁止在映射函数内修改同一 map（会死锁）。即使 cache 未超 256 不实际执行删除，但该代码路径仍在 computeIfAbsent 保留锁期间被扫描，多线程竞争时可死锁。
- **修复 1**：移除 generateChunk 内的 LRU 淘汰，抽为独立的 `pruneIfNeeded()` 在 `getChunkCells` 的 computeIfAbsent 外部调用。
- **根因 2**：`getOrInitTerrain()` 用 `if (sharedTerrain == null)` 竞态检查（volatile 不足原子化），19 线程同时进入 → 19 次重复初始化。
- **修复 2**：改为双重检查锁定 `synchronized(GeoGenesisGenerator.class)` 确保只创建一个共享引擎。
- 编译通过（BUILD SUCCESSFUL）。

## 省场形态重构：每省独立 shape 曲线 + 域扭曲（2026-07-14 执行）

### 用户核心洞察
1. 不同地形类型应有不同尺度/形状：尖顶、平顶、宽跨——形态各异。
2. 每省噪声应"乘平方回到0"：谷底塌缩到省基座（该地形类型噪声真0），避免侵蚀从平整高台硬刻、陷入局部极小值。
3. 明确否决旧 Ridge 算子 `1-|2n-1|`（把山脊落在噪声中点零值→指纹状假山脊）；峰在 n=1、谷在 n=0，山岭蜿蜒由域扭曲(warp)产生。

### 统一建模规则（已落码）
```
provEᵢ = baseᵢ + rangeᵢ·shapeᵢ(nᵢ)
shapeᵢ(0)=0（谷底=省基座=噪声真0）、shapeᵢ(1)=1（峰顶）
elevation = Σ wᵢ·provEᵢ（softmax 混合"特征"）
relief    = Σ wᵢ·(reliefAmpᵢ·detailᵢ)（保留小尺度粗糙）
e = eOcean + eLand（不变）
```

### 每省 shape 函数
- **克拉通**：保持原 `lerp(plain,hill)`（cri=0→plainBase，valley=noise0 ✓）
- **造山带**：`pow(FBM(x+warp·wX, z+warp·wZ), beltSharpness)` + lerp(foothill,peak)
  - beltSharpness=2.0（>1尖、=1圆、<1宽缓）
  - warpX/Z 频率 1/500，warpAmp=120 块 → 蜿蜒山岭（峰 n=1、谷 n=0，禁用零交叉 Ridge）
- **高原**：`terrace(n)=min(platFbm/0.6, 1.0)`，线性攀升→0.6 处封顶@platTop
- **盆地**：`basinBase+0.03·(1-n)` 倒置凹盆

### 改动的文件（5 文件 + 1 toml）
| 文件 | 改动 |
|------|------|
| `TerrainParams.java` | 加 `beltSharpness()`(2.0) / `beltWarpAmp()`(120.0) 字段+defaults |
| `LandShape.java` | belt=pow+warp、plateau=terrace、basin=invert、加 warpX/Z 噪声+seed |
| `GeoGenesisConfig.java` | 加 beltSharpness/beltWarpAmp 字段+BUILDER 默认+buildParams/defaultParams 同步 |
| `geogenesis-common.toml` | 新增 [Terrain Shape] 段 |
| `GeoGenesisConfigScreen.java` | 地形页加"山脉尖钝""山脉扭曲"两滑块 |
| `CellGenerator.java` | 无需改（LandShape 构造器自动取 TerrainParams 新字段） |

   - `beltHigh` 1/90 → 1/180（中尺度 octave 拉长）
   - `cratonDetail` 1/120 → 1/220
   - `beltDetail` 1/80 → 1/220
2. **振幅仅适度下调**（对齐分类阈值，非砍到纹理级）：
   - `cratonReliefAmp` 0.12 → **0.10**（保 HILLS）
   - `beltReliefAmp` 0.30 → **0.22**（保 MOUNTAINS）
   - 同步 6 处：TerrainParams.defaults + 字段注释、GeoGenesisConfig BUILDER 默认、run/config/geogenesis-common.toml。

### ⚠️ 回归教训（关键）
