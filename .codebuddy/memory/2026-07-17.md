## v7.5 三大修复（本会话）

### 用户反馈
截图显示两个视觉问题：丘陵太小（4-6 层阶梯≈10-15 Y块）、高原旁边直接是平原。

### 通读代码链路的根因分析

**问题 1：丘陵太小 — 三层嵌套压缩**
1. 公式层：`morphAdjust = Σw×(typeNoise − sharedNoise)/Σw` — 两个 [0,1] 噪声的差值幅值仅 ±0.15
2. 噪声层：hillsNoise 用 `Map(-1,1,0,1)` 但输入仅 [-0.6, 0.6] → 输出 [0.2, 0.8] 有效范围仅 60%
3. 尺度层：主频 1/300 + 1/80 + 1/40 太碎，非 MC 丘陵应有的 500-1000 块直径

**问题 2：高原接平原 — 无地理约束的 cell 类型分配**
`cellType()` 用 1/1500 频率 typeField 阈值分配类型，PLATEAU 可随机出现在任何位置。

### 三个修复

**Fix 1: hillsNoise 配方重写 (TypeNoiseProvider.java)**
- 从 3 频 (1/300+1/80+1/40) → 2 频 (1/400 + 1/120×0.5)
- 总振幅 ~1.5 确保 Map(-1,1,0,1) 输出接近 [0.05, 0.95]
- Warp 50→80，频率 1/60→1/150

**Fix 2: sample() 公式重写 (TypeLandShape.java)**
- 从 `base + morphStrength × diff × range` → `lo + range × typeWeighted`
- 类型噪声直接主导高度，不做差值
- PLAIN：eLand ∈ [0.034, 0.041] ≈ 2 Y 块（真正平坦）
- HILLS：eLand ∈ [0.085, 0.355] ≈ 70 Y 块（正确尺度）
- 连续性由 typeWeights 高斯平滑过渡保障

**Fix 3: PLATEAU 地理隔离 (VoronoiRegionField.java)**
- cellType 中新增：PLATEAU cell 检查 3×3 邻居是否有 MOUNTAINS
- 无 MOUNTAINS 邻居 → 降级为 HILLS
- 地理序列：平原→丘陵→山地→高原

### 编译验证
`gradlew compileJava --rerun-tasks` → **BUILD SUCCESSFUL in 15s**

## v7.8 HILLS 带宽扩展 + MOUNTAINS 地理约束（本会话后半）

### 用户反馈
截图显示地形类型图层中 MOUNTAINS（深褐）旁边直接 PLAIN（绿），无 HILLS（浅橙）过渡。

### 根因分析
1. `cellType()` 中 `typeField` 相邻 cell 之间差分可跳过原 HILLS 带宽（0.25）
2. typeField 频率 1/500, cell 间距 ~400 块 → 跨 300-500 块 Simplex 变化可超 0.25
3. MOUNTAINS **没有**类似 PLATEAU 的地理约束

**额外发现**：`hasMountainNeighbor()` 存在预存 bug——阈值范围误用 `[THRESH_MOUNTAINS, THRESH_PLATEAU)`
即 PLATEAU 范围，实际应检查 `[THRESH_HILLS, THRESH_MOUNTAINS)`（MOUNTAINS 范围）。

### 修复（VoronoiRegionField.java）

| 变更 | 旧值 | 新值 | 说明 |
|------|------|------|------|
| TYPE_THRESH_PLAIN | 0.35 | **0.28** | 收紧 PLAIN |
| TYPE_THRESH_HILLS | 0.60 | **0.65** | HILLS 带宽 0.25→0.37 (+48%) |
| TYPE_THRESH_MOUNTAINS | 0.75 | **0.78** | 对应上调 |
| TYPE_THRESH_PLATEAU | 0.90 | **0.92** | 对应上调 |
| hasMountainNeighbor | `[MOUNTAINS, PLATEAU)` | **`[HILLS, MOUNTAINS)`** | 修复阈值范围 bug |
| cellType (新增) | — | **MOUNTAINS 地理约束** | 与 PLAIN 相邻且无 HILLS → 降级 |

`gradlew compileJava --rerun-tasks` → **BUILD SUCCESSFUL in 15s**
