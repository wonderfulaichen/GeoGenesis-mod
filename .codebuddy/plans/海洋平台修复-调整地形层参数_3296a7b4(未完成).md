## 问题描述

禁用水力侵蚀后，海洋平台仍然存在，说明问题在地形层而非侵蚀层。截图显示海洋中有明显的宽浅平台：近岸海域过宽、深度变化过缓，形成不自然的"台阶"感。

## 根因分析

当前海洋深度剖面参数导致大陆架过宽、坡度太缓：

- **大陆性噪声频率**：0.0006 周/方块，周期 ≈ 1667 方块
- **oceanShelfFraction = 0.20**：大陆架覆盖 c 从 0 到 -0.20 的范围，实际距离 ≈ 167 方块
- **shelfDepth = 25**：在这 167 格内深度仅从 0 增加到 25 格，坡度 ≈ 0.15（太缓）
- **结果**：宽而浅的大陆架平台，与真实地理不符

## 修复目标

1. 缩窄大陆架宽度（减少 oceanShelfFraction）
2. 加深大陆架坡折深度（增加 shelfDepth）
3. 调整大陆坡参数以保持合理的深度过渡
4. 消除宽浅平台感，让海岸到深海的过渡更自然

## 技术方案

### 参数调整策略

**核心思路**：缩窄大陆架 + 加深浅海 + 保持大陆坡/深海/海沟的比例协调

**推荐参数对比**：

| 参数 | 当前值 | 新值 | 说明 |
| --- | --- | --- | --- |
| oceanShelfFraction | 0.20 | 0.08 | 大陆架从 20% 缩窄到 8%，实际距离从 ~167 格减到 ~67 格 |
| shelfDepth | 25 | 35 | 大陆架坡折深度从 25 格加深到 35 格，坡度从 0.15 提升到 0.52 |
| oceanSlopeFraction | 0.40 | 0.35 | 大陆坡略缩窄，保持与新大陆架的过渡 |
| deepOceanDepth | 60 | 70 | 深海略加深，增加深度梯度 |
| trenchDepth | 85 | 100 | 海沟加深，增加视觉层次 |


**效果计算**：

- 修改前：167 格内深度 0→25 格，坡度 0.15
- 修改后：67 格内深度 0→35 格，坡度 0.52（提升 3.5 倍）

### 修改文件

1. **TerrainParams.java**（默认值）
2. **GeoGenesisConfig.java**（Forge Config 定义）
3. **run/config/geogenesis-common.toml**（运行时配置）

### 海洋样条验证

当前 HeightCurve 中的海洋样条结构：

```
tKnots = {0.0, 0.08, 0.43, 0.90, 1.0}
dKnots = {0.0, 35, 70, 70, 100}
```

样条类型为 Catmull-Rom spline，会自动在控制点间平滑插值。

1. 大陆架明显缩窄（从 ~167 格减到 ~67 格）
2. 海岸到深海的坡度更陡、过渡更自然
3. 不再有宽浅的"台阶"感
4. 深海/海沟深度层次更丰富
