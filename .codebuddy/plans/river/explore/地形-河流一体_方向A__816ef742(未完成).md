## 用户需求

用户选定**方向 A**：把河流生成与新地形高度场**绑定为整体**，落实"地形与河流本是一体"的地理学原则（参考 TerraForged-0.3.x 河网绑进地形场、Streams 树枝状分叉/谷深/瀑布、Janert 水滴侵蚀思路）。

- 现状病根：`RiverField` 用旧 `Continent` 的假高度（`continentNoise×100`）定河网路径，河流**不跟随新地质过程地形**的真实排水 → 河流可能切穿山脉或落在错误低地。
- 目标：让河网由新地形 `eLand` 高度场驱动（按高度向下坡邻居连河，树枝状汇流），河床**相对本地地形高度下切**，刻蚀升级为 **valley + bank + bed 多级 + 侵蚀变壁**，并产出**连续河流遮罩**；消除旧 per-tile BFS 的 border 断点，保证确定性、分块无缝。

## 核心特性

- 河网由真实陆地高度场 `eLand` 派生（粗格点下坡汇流），天然顺地形排水入海，与海陆同源。
- 河流刻蚀在同一地形采样趟内把 **U 形河谷 + 谷肩 + 河床** 刻入 `eLand`，河床相对本地下切。
- 输出 `riverMask`（布尔，河道内，契约不变：放水/预览蓝/RIVER 类型）+ `riverWetness`（连续 0..1，平滑河湖边缘）+ `riverDistance`/`valleyWidth`（沿用）。
- 海洋处裁剪（河不入海、不穿海）。
- 湖泊由新地形低地（盆地）驱动，与新地形对齐。

## 技术栈

- Java 17 / Forge 1.20.1；零 MC 依赖纯 Java 引擎（`worldgen/river`、`worldgen/terrain`）。
- 复用现有噪声工具箱（`Simplex`/`Frequency`/`NoiseUtil`/`Ridge`）与 `TerrainBlender.sampleLand` 产出 `eLand`。
- 沿用 `CellGenerator.heightAt` 契约（雨影依赖未刻蚀的陆地高度，河蚀只在 `computeShape` 内、heightAt 之后做）。

## 实现方案

### 策略

把河网生成从"旧 Continent 假高度 per-tile BFS"重构为"**新地形高度场上的粗格点下坡汇流 + 线段距离场**"（对齐 TerraForged `RiverGenerator.computeNodes` 思路），并在 `CellGenerator.computeShape` 内用 TerraForged `RiverCarver` 式多级刻蚀取代现有 `riverIncise*(1-smooth)` 一刀切。对外 `CellGenerator`/`HeightCurve`/`BiomeClassifier`/`RainShadow`/预览 11 图层契约不变（仅新增 `riverWetness` 字段，旧 `riverMask` 布尔语义保留）。

### 关键技术决策与权衡

1. **HeightProvider 解耦**：新增函数式接口 `double landHeight(int wx,int wz)`，陆地返回 `eLand∈[0,1]`，海洋返回 `NaN`。`RiverField` 不再依赖 `Continent`，由 `CellGenerator` 注入 `this::landHeightAt`（内部调 `sampleLand` 取未刻蚀陆地高度）。彻底消除"河网用旧大陆假高度"的病根，且 RiverField 与地形引擎解耦、可独立测试。

2. **粗格点下坡汇流（取代 per-tile BFS）**：`RiverField` 内部取 `GRID≈48` 块的粗格点，每节点取 `landHeight`。`computeNodes(gx,gz)` 复刻 TerraForged：对节点 A 看 4 邻居，仅当「A 是 B 的最低邻居」(`connects`) 时把 A→B 连成河段（树枝状）；`landHeight` 为 NaN（海洋）跳过；源头（`isSource` 且连到更低邻居）按概率加 lake 节点（`hasLake`）。河段存 `RiverNode`（起止世界坐标 / 高度 / 半径 / 扰动）。**按粗格点 `LongCache`（ConcurrentHashMap by 粗格 key）缓存**，确定性、跨块无缝，无 tile border 断点。

3. **河宽近似（v1，向下游变宽）**：因无全局遍历，v1 用高度/下游位置近似 `radius = lerp(minR, maxR, (seaLevel−h)/(seaLevel−peak))` 钳制，使河流向海变宽；自然叠加树枝状结构。Strahler 全局河序定宽列为非阻塞 follow-up。

4. **线段距离场采样**：`sample(wx,wz)` 扫描最近粗格点 3×3 邻域，对每段求点到线段的投影距离 `d` 与投影 `t`：

- `riverDistance = clamp(d / radius, 0, 1)`（0=河心，1=岸边外）
- `valleyWidth = radius * valleyWidthFactor`（沿用 DRAINAGE 图层/河谷标签）
- `riverMask = (riverDistance < bedWidthFrac)`（布尔，河道内）
- `riverWetness = clipRiverNoise(1 - smoothstep(riverDistance))`（连续 0..1；`continentNoise<beach` 处置 1=干）

5. **多级刻蚀（CellGenerator.computeShape）**：用采样结果 + 本地 `eLand` 做 TerraForged 式 carve：

- `baseLevel = eLand`；`bedLevel = baseLevel − bedDepth`（相对本地下切）；`bankLevel = baseLevel + bankDepth`（谷肩抬升）
- `valleyAlpha`（U 形渐隐，lerp 平方与线性）在 `valleyWidth` 内把地形压向 `bankLevel`；`riverAlpha` 在 `bedWidth` 内压向 `bedLevel`
- `erosion` 脊线噪声扰动谷壁（`getErosionModifier`）
- `riverWetness` 连续遮罩供生物群系/放水；`continentNoise<beach` 处裁剪（河不入海）
- 移除旧 `riverIncise*(1-smooth(riverDistance))` 一刀切；`riverIncise` 配置字段由 `riverBedDepth/riverBankDepth/riverValleyWidth/...` 取代。

6. **湖泊**：`LakeGenerator` 改为由新地形低地（盆地 `eLand` 近 `basinBase`）驱动，与新地形对齐；源头 lake 节点来自 `computeNodes` 的 `isSource` 分支。

### 性能

- 河网仅在粗格点（每 ~48 块）采样 `landHeight`（= `sampleLand`，4 省 relief + softmax），频率约为逐块采样的 1/2304，开销可忽略。
- `sample(wx,wz)` 仅扫描 3×3 粗格点 × 少量河段，O(常数)；无全局/跨块遍历。
- 缓存按粗格点 `LongCache`，与 TerraForged 同范式，确定性、无缝。

### 防回归

- `Cell.riverMask` 布尔语义**必须保留**（放水 / 预览蓝着色 / `RIVER` 类型序号 / DRAINAGE 图层均依赖）。
- `riverDistance`/`valleyWidth` 保留（被 DRAINAGE 图层、河谷标签消费）。
- 河蚀只在 `computeShape` 内、调用 `heightAt` 之后执行，`RainShadow`（依赖未刻蚀高度）不受影响。
- `worldgen/river`、`worldgen/terrain` 不 import MC（保持零依赖）。
- 旧 `BaseRiverGenerator` 逻辑并入 `RiverField` 后删除，避免双份河网逻辑。

## 架构设计

```mermaid
flowchart TD
    A[CellGenerator.computeShape] --> B[continent.sample c / sampleLand → eLand]
    B --> H[heightAt 复用 eLand 供 RainShadow 雨影]
    B --> C[RiverField.sample + HeightProvider.landHeightAt]
    C --> D[粗格点 computeNodes: 4邻居下坡连河 connects / 海洋NaN跳过 / 源头加lake]
    D --> E[RiverNode 线段: 坐标/高度/半径/扰动]
    E --> F[3x3粗格扫描: 点到线段距离 → riverDistance/valleyWidth/riverMask/riverWetness]
    F --> G[CellGenerator 多级刻蚀: valley+bank+bed + erosion + 海洋裁剪]
    G --> I[e = carveValley(eLand) * lm 海岸淡出]
    I --> J[HeightCurve.height / classify → BiomeClassifier]
    F --> K[riverWetness 连续遮罩 → 放水/预览平滑边缘]
```

## 关键代码结构（接口级）

```java
// 河网高度提供器：解耦 RiverField 与 Continent，由新地形 eLand 驱动
@FunctionalInterface
public interface HeightProvider {
    /** 陆地返回 eLand∈[0,1]；海洋返回 Double.NaN（RiverField 跳过该节点）。 */
    double landHeight(int worldX, int worldZ);
}

// 河段线段（对齐 TerraForged RiverNode）
public final class RiverNode {
    public RiverNode(double ax, double ay, double bx, double by,
                     double ah, double bh, double radius, double warp) { /* ... */ }
    public double getProjection(double x, double y);   // 点到线段投影参数 t∈[0,1]
    public double getDistance2(double x, double y, double t); // 投影点距离平方
    public double getRadius(double t);                 // 沿线半径插值
}

// RiverField 采样结果载体（替代临时 Cell 复用）
public final class RiverSample {
    public double riverDistance;  // 0=河心,1=岸边外（= d/radius）
    public double valleyWidth;    // 河半径（DRAINAGE/河谷标签）
    public boolean riverMask;     // 河道内（布尔，契约不变）
    public double riverWetness;   // 连续 0..1（平滑边缘/放水）
}
```
