## 用户需求

重做侵蚀前基础地形的"地质省形态"模型，让不同地形类型呈现**各异的形态与尺度**（山脉尖峰+蜿蜒宽跨、高原平顶台地、盆地凹地、平原缓丘），并修正当前每省基面"正 pedestal"问题——让地形类型噪声的谷底回到该省基座（噪声真 0），使初始地形自带真实河谷，避免后续水力侵蚀从平整高台硬刻、易陷入局部极小值。

## 产品概述

在保持现有"统一连续场 e=eOcean+eLand、海岸自然涌现、海拔×起伏二维分类"契约不变的前提下，把 `LandShape` 每省的 `lerp(floor,top,fbm)` 替换为**每省独立 shape 曲线**（谷底=baseᵢ、峰顶=baseᵢ+rangeᵢ），通过幂函数（平方/尖钝）+ 域扭曲（warp）实现形态各异，并新增 `beltSharpness`/`beltWarpAmp` 两个可调参数接入配置 UI。

## 核心特性

- **每省形态各异**：克拉通=平滑缓丘；造山带=`pow(n, sharpness)` 尖峰 + warp 蜿蜒山岭；高原=`terrace` 平顶台地+崖缘；盆地=倒置凹盆。
- **谷底回归噪声真 0**：`provEᵢ = baseᵢ + rangeᵢ·shapeᵢ(nᵢ)`，`shapeᵢ(0)=0`、`shapeᵢ(1)=1`，谷底塌缩到省基座（略高于海平面），初始地形自带真实河谷，利于侵蚀顺谷下行。
- **否决假山脊**：明确不使用 `1-|2n-1|` 零交叉脊函数（会把山脊落在噪声中点零值，呈指纹状假山脊）；山体 elongated 蜿蜒由域扭曲产生。
- **参数入 UI**：`beltSharpness`（尖钝）、`beltWarpAmp`（山岭弯曲幅度）接入配置屏滑块，满足"参数必须进配置 UI"。

## 实现思路

把"侵蚀前基础地形"从"每省 lerp(floor,top,fbm) 正 pedestal"重构为**每省独立 shape 曲线建模**，核心公式：

```
nᵢ          = saturate((rawNoiseᵢ + 1) * 0.5) ∈ [0,1]      // 地形类型噪声（非大陆性条件噪声）
provEᵢ      = baseᵢ + rangeᵢ · shapeᵢ(nᵢ)                    // shapeᵢ(0)=0 谷底=baseᵢ，shapeᵢ(1)=1 峰顶
elevation   = Σ wᵢ · provEᵢ                                // softmax 混合"特征"而非最终高度
relief      = Σ wᵢ · (reliefAmpᵢ · detailᵢ)                // 保留小尺度粗糙（detail∈[-1,1] 已居中，无需改）
eLand       = clamp(elevation + relief, 0, 1)
e           = eOcean + eLand                               // 加法模型、海岸自然涌现（不变）
```

**每省 shape 函数（形态各异来源）**

- 克拉通：`smoothstep(n)`（低 power、低频）→ 缓丘/平原，谷底=`plainBase`。
- 造山带：`pow(n, beltSharpness)`（默认 2.0，>1 尖顶、=1 圆顶、<1 宽缓）+ **域扭曲**：belt 噪声在扰动坐标 `(wx + warpAmp·warpX, wz + warpAmp·warpZ)` 采样，`warpX/warpZ` 为低频 Simplex；warp 把高 n 团块拉成蜿蜒山脉，绝不用零交叉脊函数。
- 高原：`terrace(n)` = 超阈值钳到 `platTop`（平顶台地 + 崖缘过渡）。
- 盆地：`(1 - n)` 倒置（中心低、边缘高，凹盆）。

**为何否决旧 Ridge**：`1-|2n-1|` 把山脊落在噪声中点零值，产生指纹状假山脊、极不自然；本方案峰在 `n=1`、谷在 `n=0`，蜿蜒形态完全由 warp 产生。

**"平方回到 0" 的正式化**：即 `pow(n,k)` 使低值塌缩到 `baseᵢ`（该省噪声真 0），峰被 sharpen；`baseᵢ` 略高于海平面（foothill≈0.12 等），内陆谷底不会落到 `e=0`（否则被 `classify` 判成海洋/海滩）。初始地形自带真实河谷，河流自然沿谷下行，侵蚀是"强化"而非"硬刻"，根治局部极小值陷阱。

## 实现备注

- **性能**：每格新增 belt warp 2 次低频噪声 compute（仅 belt 采样用扰动坐标），总噪声约 19 次/格，仍 O(1)/格，产线复杂度不变；warp 噪声节点需在 `seed()` 显式播种（参照现有 `platLow` 等不在 root 内的节点，避免 NPE 卡死）。
- **回归控制**：`OCEAN/DEEP_OCEAN/BEACH` 前置与 `e<0` 判洋逻辑不动；海岸线仍由 `e` 自然过零涌现；`eLand` 连续 + 省权重连续 → 类型平滑过渡、无硬边、无 tile 接缝；`height` 映射与方块填充链路不变；`classify` 海拔×起伏矩阵、`applySnowLine`、`BiomeClassifier.isSnow` 覆盖全部不动。
- **侵蚀/河流 apply 仍注释**（待本项稳定后恢复），本项只改侵蚀前基础地形。
- **配置同步铁律（6 处）**：`GeoGenesisConfig`(BUILDER默认+defaultParams) + `TerrainParams`(record+defaults) + `geogenesis-common.toml` + `GeoGenesisConfigScreen.buildParams` + `GeoGenesisGenerator` 接线 + 预览 `defaultParams()`；改默认后必须同步已存在 toml。
- **日志**：不改日志；标定阶段可在 `classify` 临时打各 `TerrainClass` 占比直方图，确认后删除。

## 架构设计

侵蚀前基础地形由"地质省 shape 曲线"连续合成双场（海拔 + 起伏），分类与雪线解耦；新参数接入配置屏实时预览并落盘：

```mermaid
flowchart LR
  TOML[geogenesis-common.toml] --> SPEC[ForgeConfigSpec BUILDER 默认]
  SPEC --> BP[buildParams / defaultParams]
  BP --> TP[TerrainParams 含 beltSharpness/beltWarpAmp]
  TP --> LS[LandShape: provinceWeights + 每省 shapeᵢ(nᵢ) + warp]
  LS -->|elevation, relief| CG[CellGenerator.sample]
  CG -->|eLand=elevation+relief| E[e=eOcean+eLand]
  CG --> CL[classify: 海拔×起伏 矩阵 -> TerrainClass]
  CG --> SN[applySnowLine: 海拔×温度 -> isSnow]
  CL --> BC[BiomeClassifier: switch(terrainType) + isSnow]
  E --> GEN[GeoGenesisGenerator.fillFromNoise]
  BP -->|本地副本| SCR[GeoGenesisConfigScreen]
  SCR -->|实时预览| PV[PreviewDisplay]
  SCR -->|保存| SPEC
```

## 关键代码结构（核心改动示意）

`LandShape.sample` 每省 shape 曲线（谷底=baseᵢ，峰顶=baseᵢ+rangeᵢ）：

```java
// 造山带：pow 尖峰 + 域扭曲（warp 产生蜿蜒山岭，禁用零交叉脊函数）
double bx = warpAmp * warpX.compute(wx, wz);
double bz = warpAmp * warpZ.compute(wx, wz);
double nBelt = saturate((beltNoise.compute(wx + bx, wz + bz) + 1) * 0.5);
double beltShape = Math.pow(nBelt, beltSharpness);      // shape(0)=0, shape(1)=1
// 高原：terrace 平顶
double platShape = (nPlat < platFlat) ? smoothstep(0, platFlat, nPlat) * 0.6 : 1.0;
// 盆地：倒置凹盆
double basinShape = 1.0 - nBasin;
// 克拉通：平滑缓丘
double cratonShape = smoothstep(0, 1, nCraton);
// 基面 = baseᵢ + rangeᵢ · shapeᵢ(nᵢ)
double provE = base + range * shape;
```
