## 一、对拍口径

对 `D:\Office software\Development Project\GeoGenesis-offrepo-20261103` 下**每一个文件**计算：

- `size`
- `SHA-256`（独立校验）
- `git blob SHA-1` = `sha1(b"blob <size>\0" + bytes)`，与 `git hash-object --no-filters` 同义

然后判断该**内容**是否还能在别处找到（按内容，不按路径/文件名）：

| 分类 | 含义 |
|---|---|
| `both` | 既在主仓库 git 对象库，也在当前工作区 |
| `git_objects` | 只在对象库（`git cat-file --batch-all-objects` 覆盖所有 ref/历史/stash/不可达对象） |
| `workspace_only` | 只在工作区磁盘上（**不在版本库**，但当下还看得到） |
| `orphan` | 两处都没有 ⇒ 删掉备份即丢失 |

主仓库工作区 29 GB / 12.5 万文件，用「大小预筛 + 逐字节 hash」避免全量读盘。
