scope=RegionalMorphWorld P3 sandbox: per-1024-tile LocalBoundaryGeometry -> site weights -> per-site recipe draw -> merged 23 weights -> shared NodeMorphEngine
canonical_seed_only=only RecipeMorphCatalog.GALLERY_SEED. FullMorphLand rejects every other seed, and this check adds no seed of its own
pure_land=bitwise, tolerance 0. The check also records and asserts the normalize invariant Sum(w[0..17]) == 1.0 on pure-land points. FullMorphLand.normalize patches the rounding residual into the argmax entry and the ocean slots stay +0.0 on a pure land point, so adding them cannot change the partial sum. NOTE: this is the merger's invariant, NOT evaluate()'s branch condition -- the former 'landWeight == 1' test is exactly what the landWeight==1 trap broke (see next entry)
landweight1_trap=REGRESSION for the defect the full Gallery export hit: with w[0]=1.0 and one ocean component = 1e-18 (also 1e-20 and Double.MIN_VALUE), BOTH the in-order land sum and the full sum are exactly 1.0 (because 1.0 + eps rounds back to 1.0), yet an ocean component is genuinely positive. A sum-based pure-land test therefore misclassifies the vector and NodeMorphEngine.sampleLand rejects it with 'land-only weights required'. The fixed evaluate() must inspect whether any ocean component is actually > 0; this check asserts (a) evaluate returns a finite value, (b) it is bitwise engine.sampleE + landWeight*delta, and (c) at points where the two branches are numerically distinguishable it demonstrably takes the mixed branch rather than the sampleLand shortcut
trap_eps_caveat=only eps values for which 'landWeight + eps == 1.0' in double actually construct the trap; the check skips (and reports the count of) any eps that does not, rather than fabricating a pass
ocean_slot_reachability=REGRESSION for the defect main's audit found: RefNoise.hash2D ends with 'hash ^= hash >> 13' using an ARITHMETIC shift, which copies the sign bit back in and leaves the sign bit at 0, so the return value is a 31-bit non-negative int rather than uint32. unit(h) = h * 2^-32 therefore yields draw in [0, 0.5), and (int)(draw * 12) can only reach ocean slots 0..5, so slots 6..11 and any ocean recipe that lives only there never appear. The fix is unit(h) = h * 2^-31. This check (a) reflects the implementation's own unit()/base(), (b) recomputes the slot independently of the oceanSlots table over cellX/cellZ in [-50,50] and requires all 12 slots reachable plus unit max > 0.99 and min < 0.01, (c) requires choose() to agree with that recomputation cell by cell on the real code path, and (d) requires all 5 ocean recipes to be chosen at least once over a wider cell grid
ocean_slot_not_self_proof=the gate is 'every slot reachable' and 'each ocean recipe chosen at least once'. No count is compared against UnifiedTerrainCatalog.buildOceanSlots' expansion table, so the check cannot pass by agreeing with itself. oceanSlot is computed unconditionally in choose(), i.e. regardless of isSea, so the reachability claim does not depend on constructing a point that is actually classified as sea; the check does nonetheless report the sea/land split of its sample
pure_sea=bitwise against an independently constructed NodeMorphEngine.sampleE. Structural argument: landWeight == 0 makes the coverage term landWeight*delta exactly 0, so a pure sea sample can only equal the bare engine evaluation; the cover guard {landWeight>0 && alpha>0} is asserted to fire zero times
identity=cell identity is decided per (cellX,cellZ) from the inverse-warped site position, so two INDEPENDENT RegionalMorphWorld instances over different (including neighbouring and overlapping) geometry windows must produce bit-identical SiteChoice records. The second world never calls tileAt, so its choices are always first-time computations; this is what makes the check more than a cache self-proof. A reverse-order rebuild of recipes[] is included
identity_window_note=LocalBoundaryGeometry windows are narrow (radius 728 blocks with a 120-block halo over a ~3600-block cell grid), so only a handful of cells are shared per window pair. The measured shared-cell count is written out; the gate only requires that at least one shared cell exists and that ALL shared cells agree
cross_tile=the same world point is force-sampled through BOTH tiles that contain it near a tile boundary, using sample(tile,x,z) which bypasses tileAt. Tolerance 2e-3 on weights and on e is inherited from the geometry (120-block weight band, 0.02-block inverse-warp residual, 2-block maximum segment). Measured values are written out; a failure is NOT relaxed
boundary_convergence=weights must converge as eps -> 0 (|dw(0.01)| <= 0.25*|dw(1)| + 1e-6). That is the real step detector. Height is deliberately NOT required to be smooth: badlands Steps and the plateau Terrace carry intrinsic steps, so the height criterion only demands |de| <= (the two endpoint recipes' own hard-field change) + (weight change) *(endpoint spread). Requiring a globally C1 height field would be wrong
band_240=progress(s) is verified to be exactly one smoothstep of s/240 with a 120-block half width whose saturation edges are measured by bisection rather than assumed, and the double-ease counterexample is quantified so that gate is not vacuous. One land-land boundary is profiled across +/-360 and its A->B crossover is measured as the s-range where wA stays strictly inside (0,1); the live measurement is written to band-240.csv / metrics.txt (band240.width_blocks) rather than restated here, because it depends on 0.5-block sampling and on which boundary the sweep happens to pick.
