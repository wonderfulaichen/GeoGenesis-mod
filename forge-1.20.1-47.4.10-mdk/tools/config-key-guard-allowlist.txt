# config-key-guard 白名单（runConfigKeyGuardProbe 读取）
#
# 格式：<键名><TAB><理由>
#   · 每条必须有理由 —— 空理由会让探针直接 FAIL。
#   · 白名单不是永久豁免：条目对应的键若变成「被生产消费」，或该键已从配置里消失，
#     探针同样 FAIL，用来强制清理腐烂条目。
#   · 新增条目前先想清楚：这个键真的不该驱动产出吗？还是应该接通/删除？
#
# 2026-11-07 清理：本文件原有 8 条豁免，全部指向本轮删除的死键
#   （erosionLocalChargeWeight / erosionRoutingAdaptive / hydrologySkeletonRouting /
#     hydrologyDecayEnabled / hydrologyDecayMax / hydrologyDecayRef / hydrologyDecayExponent /
#     hydrologyModelPipelineEnabled），随键一并删除 ⇒ 当前**没有任何豁免**。
#   这正是白名单应有的状态：它应该有牙齿，让"删了键就必须删条目、条目只剩理由"成为常态。
