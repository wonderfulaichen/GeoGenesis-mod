# 2026-06-02 性能优化与侵蚀重构

## 一、侵蚀算法重构（TerraForged 风格）

### 问题
旧版多层级侵蚀（3层 r=8/4/2，7700粒子/chunk）把地形完全压平：
- 方差=0，梯度=0，粗糙度=0
- 原因：低惯性(0.001) + 高蒸发(0.35) + 低沉积率(0.06-0.18)

### 解决方案
参考 TerraForged 源码，改为单层 + 少粒子 + 高惯性：

| 参数 | 旧值 | 新值 |
|------|------|------|
| 层数 | 3层 (r=8/4/2) | **1层 (r=4)** |
| 每 chunk 粒子数 | ~7700 | **350** |
| 惯性 | 0.001 | **0.05** |
| 高度衰减 | 0.5 | **0.4** |
| 蒸发 | 0.35 | **0.01** |
| 沉积率 | 0.06-0.18 | **0.3** |
| 重力 | 2.5 | **3.0** |
| 搬运因子 | 10 | **4** |
| 生命周期 | 120 | **30** |
| 高斯平滑 | 有 (σ=1.5) | **无** |

### 关键技术
- **共享笔刷**：预计算笔刷偏移和权重，避免每步重复计算
- **一维数组**：`float[]` 替代 `float[][]`，缓存友好
- **双线性插值沉积**：沉积到4个节点，自然平滑
- **高度衰减**：`falloff = height >= 0.4 ? 1 : height/0.4`，低地不被侵蚀

### 效果
- 侵蚀耗时：254ms → 35-80ms（**2-3倍提升**）
- 地形保留：方差从0恢复到正常值
- 地形正常，不再被压平

## 三、噪声生成性能分析（当前最大瓶颈）

### computeHeight 每像素调用统计
- **~120 次 `ImprovedNoise.noise()` 调用**
- tileSize=112×112=12,544 像素 → 总计 ~150万次噪声调用
- 噪声耗时：67-350ms/chunk，占总时间 50-70%

### 主要开销来源
| 采样方法 | domainWarp | FBM octaves | 估计 noise 调用 |
|---------|------------|-------------|----------------|
| sampleContinentRaw | 5次warp | 3+3(ridge) | ~14 |
| sampleTerrainBase | 1次warp | 2+1 | ~10 |
| sampleRidge | 1次warp | 5 | ~19 |
| sampleCellNoise | 1次warp | 3 | ~16 |
| sampleElevation | 无 | 4 | 12 |
| sampleTerrainHills | 无 | 4 | 12 |
| sampleGullyErosion | 无 | 2+2 | 12 |
| samplePlateauWeight | 无 | 2 | 6 |
| sampleKarstWeight | 无 | 2 | 6 |
| sampleGlacierWeight | 无 | 2 | 6 |
| sampleValleyLarge | 1次warp | 2 | ~10 |
| sampleTerrainDetail | 无 | 2 | 6 |

### 优化方向（未实施）
1. **共享 domainWarp** — 多个采样复用同一 warp 结果（最大收益）
2. **降低 FBM octaves** — 4-octave 降到 2-3
3. **合并相似采样** — plateau/karst/glacier 用同一噪声不同偏移
4. **预计算 domainWarp** — tile 级别预计算 warp 偏移表
